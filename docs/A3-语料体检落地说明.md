# A3 落地说明 · 微调语料体检与一键剔除

> 对应《功能完善建议-2026-09-05》A 档第 3 条。commit `b0960e6`。

## 解决什么问题

clip_qc 打分早就接进了切片流水线（每条切片都有 A/B/C/D 等级徽章），但 **`/ft/train` 训练入口从来没消费这个分数**——D 级废片（近静音、爆音、错人声）照样进训练集，直接污染音色。袋鼠音色"鬼叫"的根因之一就是脏切片进训。

现在：切片处理完自动体检 → 检出废片给出原因 → 一键剔除（可恢复）→ 再开训。

## 功能入口

**前端**：微调页「处理完成」卡片内新增「语料体检」面板。

- 等级分布徽章：A/B/C/D 各级条数 + 均分 + 净时长
- D 级 > 0 时红字提示废片原因（如「响度过低 ×4」）
- 剔除粒度切换：**只剔 D 级**（默认）/ **C 级也剔**
- 「一键剔除并重选锚点」「恢复全部」
- 切片数变化时自动重新体检（带指纹缓存，不会反复重算）

**后端 API**：

| 端点 | 方法 | 说明 |
|---|---|---|
| `/api/ft/corpus_qc?voice_id=&force=` | GET | 体检报告（按 clips 指纹缓存，force 强制重算） |
| `/api/ft/corpus_prune?voice_id=&keep_grades=A,B` | POST | 剔除非保留级切片 |
| `/api/ft/corpus_restore?voice_id=` | POST | 恢复全部已剔切片 |

**训练闸门**：`/api/ft/train` 启动前自动体检，检出 D 级切片时响应带 `qc_warning` 字段（**不阻断训练**，是否剔除由用户决定——避免自动删数据）。

## 剔除的行为语义（重要）

1. **只移文件不销毁**：被剔切片从 `ft/<id>/clips/` 移入 `ft/<id>/rejected/`，wav + 转写一并保留。
2. **train.jsonl 同步重写**：只保留存留切片的行，转写文本不丢。
3. **锚点重选**：锚点参考音如果被剔除，自动从存留切片里重新挑（时长最长、B 级以上）；剔除后所有行的 `ref_audio` 指向有效文件。
4. **下限告警**：剔除后净时长 < 120s 时返回 `warning`（音色库现有音色不受影响，仅提示）。

## 已知边界

- 体检分数复用 clip_qc 的确定性指标（响度/静音比/削波/时长/声纹一致性），不含 ASR 文本质量——whisper 同音错字问题（QLoRA 路线曾踩过）不在本功能覆盖内。
- 自动体检依赖 `stage === "ready"` 且 `clips` 数变化；手工往 clips 目录塞文件后请点「重新体检」。
