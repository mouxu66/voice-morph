## 2. 问题清单（按严重度）

### P0 · 卡死新用户第一公里

**U1 配对全靠手填 IP**
- 移动端设置页要求手输 `http://192.168.1.10:8000`（`mobile/app/settings.tsx:88`），普通用户根本不知道 PC 的局域网 IP；连接失败只有一句通用文案（401 已区分，其余未区分"IP 错 / 端口防火墙 / 服务没起"）。
- 对应竞品 P7（设备配置是全行业出现度最高痛点）+ M4 任务 T1 预判卡点。
- **建议**：桌面端设置/体检面板显示**二维码**（含 host + API Key），手机"扫码配对"；失败文案按错误类型分流（超时→防火墙提示；拒绝→端口提示）。成本：低。

**U2 移动端音色获取断头**
- `voices.tsx` 只显示 PC 训练音色（微调/克隆/RVC 就绪/QC 徽章），**无市场浏览/试听/安装入口**——手机用户手里没音色时只能跑去 PC 操作，主场景"手机是入口"在音色获取上断裂。
- **建议**：移动端接市场列表 + 试听 + 安装（后端 `/api/market/*` 全在，纯 App 端接线）。成本：中。

### P1 · 影响上手效率与留存

**U3 导航 9 项平铺，新用户无法回答"我该点哪"**
- `StudioNav.tsx`：音色工坊 / 发掘音色 / 音色微调 / 音色库 / 音色市场 / 语音合成 / RVC 实时 / 千问变声 / 离线工坊——**5 个"音色"系入口**难以区分（工坊 vs 发掘 vs 微调 vs 库 vs 市场），且"千问变声""RVC 实时"是模型术语（竞品测评里"新手找功能要摸索半天"是真实扣分项，对应 M1-O1/O3）。
- **建议**：按用户目标分组两行——「做音色：工坊/发掘/微调/库/市场」｜「用音色：实时变声/RVC 实时/离线工坊」，"千问变声"改名"打字变声"或"文字变声"。成本：低。

**U4 RVC 实时页无健康指标，无"机关枪卡顿"自诊**
- 千问页有 p95 面板，`LivePage.tsx` 没有；实时卡顿是竞品帮助中心第一 FAQ（M1-P4），而本产品 Live 页参数全裸露（音调/index rate/采样长度等）无预设档。
- **建议**（=M1-O2 收窄落点）：Live 页加延迟/推理耗时指示 + "低配模式"一键预设 + 卡顿自诊文案。成本：中。

### P2 · 打磨项

**U5 术语/内宣外露**：移动端设置写"三种 GPU 任务互斥（409）"（`settings.tsx:149`）、变声页"避免争抢显卡"；pitch/index_rate 裸英文参数；工坊页 "STAGE 01 / SOURCE REVIEW" 装饰英文。小白距离感。
**U6 移动端错误透传**：`catch` 后多为一句话或 e.message 直出，未过 friendlyError 等价层（桌面端已有该机制）。
**U7 下轮未走查**：Discover/Ft/SeedVc/Effects 四页 + 微信 PC 端发送流程的失败恢复路径。
