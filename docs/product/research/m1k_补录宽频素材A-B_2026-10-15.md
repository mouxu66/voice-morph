# m1k · 补录宽频素材混训 A/B（supp2026 vs 现役 t03 vs t00）

> 日期：2026-10-15。承接 `m1g`（旋钮救不了"闷"）/`m1j`（预加重治闷，不需重录）。
> 用户按 `media/raw_recordings/2026-10-supp/录制稿.md` 补录 4 条（说话 2 + 唱歌 2）。
> 全部数字 ✅ 本机实测，可复算（脚本与 json 见末尾）。

## 0. 一句话结论

**新素材本身极成功（8–11k 比旧素材高约 40dB、零削波），但"原样混训 2.8 分钟"没有整体超过
现役的 t03（旧素材 +3dB/oct 预加重）**：presence 与"像你"两项 t03 两段都赢，只有"不沾原唱"
supp 两段都赢。**现役模型先不换**；补录素材的正确用法很可能是"宽频新素材 + 预加重"，待一次
A/B 验证。最终以用户耳朵为准（试听页已交付）。

|---|---|---|---|---|---|---|---|
| 新·词语 | 32.5s | 0.62 | 0 | −19.6 | **−31.0** | −44.2 | 499Hz |
| 新·句子 | 45.2s | 0.80 | 0 | −21.7 | **−29.1** | −40.3 | 557Hz |

- 说话两条 8–11k 比旧素材**高约 40dB**——真录到了以前全空的高频（近距手机麦克风），不是调亮。
- 唱歌以持续元音为主、辅音少，高频天然低于说话（长音 −63 是纯元音的正常形状）。
- 旧素材峰值只有 0.15–0.26（录太小声），新的 0.56–0.80 电平健康；说话底噪 −66dB 很干净。

## 3. A/B：同一分离人声 / seed / pitch −12 / index 0.5，只换权重

两段不重叠的 45s 歌声最密窗口：段1 85–130s、段2 175–220s（全曲最响的 185–210s 在段2）。

| 指标 | t00（旧原样） | **t03（现役预加重）** | supp（补录混训） |
|---|---|---|---|
| 4–8k 段1 / 段2 | −27.2 / −30.8 | **−21.4 / −27.8** | −24.3 / −36.6 |
| 8–11k 段1 / 段2 | −67.1 / −66.3 | −58.4 / −58.2 | **−52.9** / −59.7 |
| CAM++ 对你 段1 / 段2 | 0.496 / 0.557 | **0.536 / 0.600** | 0.468 / 0.529 |
| CAM++ 对原唱 段1 / 段2 | 0.183 / 0.224 | 0.157 / 0.168 | **0.153 / 0.122** |

**跨段方向（#167：两段同号才算数）**：
- **4–8k（presence/亮度，正是"闷"的频段）**：t03 两段都最亮；supp 段1 居中、段2 甚至低于 t00（−5.8）。
- **像你（CAM++ 对你）**：t03 > t00 > supp，**两段一致**。
- **不沾原唱（CAM++ 对原唱，越低越干净）**：supp 两段都最低；t03 次之；t00 最差。
- 8–11k：supp 与 t03 都比 t00 高约 7–14dB，两者互有胜负（supp 段1 赢 5.5，段2 输 1.5）。

> CAM++ 是**说话人验证**尺子、且三臂同带 −12 移调，只能读三臂之间的相对排序，
> 绝对值带音高偏置（见 `cover_pitch_ruler` 的结论）。

## 4. 为什么宽频新素材没直接赢（假设，未证）

1. **只占 2.8/15 分钟（19%），且没做预加重**；t03 是把**全部 12 分钟**的 2k 以上都抬了 +3dB/oct。
   presence（4–8k）上 t03 的剂量更大更均匀——supp 的新素材虽宽，但被旧 12 分钟原样素材稀释。
2. 新素材 23% 是**唱歌**，说话辅音密度（4–8k 的主要来源）低于纯说话；模型的 presence 学的是全集形状。
3. "对原唱相似度更低"可能是收益（更少泄漏，正是 m1g 的真因①）也可能是更不像目标的副产品，
   单一 CAM++ 分不出——交耳朵。
4. 这与 m1j 不矛盾：m1j 已证"预加重"在**三份独立数据**上抬高频；本臂恰恰**没对旧素材预加重**，
   等于没给那 12 分钟加杠杆。

## 5. 后续（按性价比）

1. **★ 把 t03 的预加重也施加到含新素材的数据集**（旧 12min +3dB/oct + 新 2.8min 宽频原样或轻抬），
   训一版 `supp_t03` —— 大概率同时拿到 t03 的 presence 与 supp 的低泄漏。**这是最可能赢的一版。**
2. 想要更干净的因果：一版"旧素材原样 + 新素材"（=supp，已做）vs"旧素材预加重 + 新素材"（待做），
   只差"旧素材加不加重"一列。
3. 现役是否替换 = 用户听两页 A/B 后拍板；客观分不支持自动切换。
4. 新素材的唱歌切片可单独评估对"高音段像不像你"的作用（本次未拆）。
