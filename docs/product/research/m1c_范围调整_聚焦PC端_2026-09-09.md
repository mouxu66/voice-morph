# M1c 范围调整记录：聚焦 PC 端 · 2026-09-09 用户拍板

> 效力：本记录为产品范围与研究方向调整的**权威依据**；《00_产品界定》§3/§6/§7.2、《05_用户研究计划》、M1/M1b 清单中与之冲突的条目以本记录为准，待下次文档更新时同步修订。

---

## 1. 决策内容

- **主要关注 PC 端**。理由：手机端变声链路需要额外设备/线材/连接配置，用户不会为此购买与折腾——投入产出不成立；且移动端无 root 注入墙本来就是行业死结。
- 口径变更：产品界定 §6"手机是入口，低端是信任状" → 降级为 **"PC 是产品本体；移动端 App 维持'遥控器'现状，不再追加新功能投入"**。
- 主场景落地路径收敛为两条 **纯 PC 路径**：
  1. **PC 微信/QQ 语音条自动发送**（`wechat_voice.py` 虚拟声卡 + Alt 触发，竞品零覆盖的独占能力）；
  2. **PC 实时变声**（RVC via 虚拟声卡 → 游戏/Discord/OBS/微信通话）。

## 2. 证据复盘（为何这个转向与 M1 数据一致）

1. **移动实时是全行业死结**：iOS 权限封闭"外放收音延迟杂音"、Android 无 root 注入墙（04 传输方案评估）、竞品手机 App 全部退守"录好再变"（M1-P3，4 源）。做移动实时 = 陪行业一起撞墙。
2. **PC 端竞品痛点成集，而我们恰好全占反位**：
   - Voicemod：全英文、免费每天 1 小时、终身 300+ 元、低配卡顿；
   - iMyFone：免费每次半小时、安装包大、素材下载慢；
   - MorphVOX：界面老旧、3 天试用、参数复杂新手调不好；
   - 通用：虚拟声卡/设备配置门槛（P7）、游戏抢显卡卡顿（P4）。
   - 我们的 PC 对位：**中文、免费、真声克隆、8GB 显存友好、开箱即用**——每一个都打在差评点上。
3. **"手机是入口"的唯一被验证需求（微信语音条变声）已由 PC 路径覆盖**：wechat_voice.py 自动发送直达微信，无需手机参与。

## 4. 《05 用户研究计划》修订（PC-first 补丁）

1. **目标人群**：改为"有 PC（最好 NVIDIA 显卡）+ 微信/QQ 社交 / 游戏 / 直播场景"的用户；"低端安卓机"细分删除；招募渠道加 B 站 RVC/Voicemod 教程评论区、直播工具群、变声 PC 软件社群；
2. **问卷调整**：Q6 工具清单加 PC 竞品（Voicemod / iMyFone / MorphVOX / Papagei / 智音）；Q17"手机作无线麦接受度"降为可选；Q3 手机型号改为**显卡档位 + PC 配置**；
3. **M4 可用性任务卡改 PC 侧五任务**：
   - T1' 首次打开 → 环境体检 → 完成第一条变声（观测首启引导）；
   - T2' 打字 → 克隆音色 → 自动发到微信（观测 wechat_voice 引导与降级路径）；
   - T3' 开启 RVC 实时 → 选音色 → 在微信通话里试说（观测设备切换与 A2 健康面板效果）；
   - T4' 市场试听 → 安装 → 用新音色变声（观测试听→安装转化，对应 A2 市场试听已建）;
   - T5' 离线变声一段录音 → 调参数 → 保存（观测参数裸露问题的真实影响）；
4. **M3 深访追加**："你为变声买过什么设备/线材吗？"（验证本次"用户不买设备"的判断）。
