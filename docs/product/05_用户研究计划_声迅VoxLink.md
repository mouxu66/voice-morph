> 前置口径：本文档基于《00_产品界定》（2026-09-03 主场景调整版）制定。研究结论须回写《03_产品路线图》变更日志。
> 状态：**计划稿（数据未采集）**。§8 提供结果分析框架与报告模板，数据回收后直接套用。
> 执行约束：个人开发者、预算 ≤¥300、无推广渠道，采用精益混合方法（3 周）。

## 1. 研究背景与目标

### 1.1 为什么现在做

三个待拍板的决策都缺用户证据，目前只有技术判断：

| 待决策事项 | 当前依据（不充分） | 需要研究回答 |
|---|---|---|
| 主场景 = 微信/QQ 语音包（2026-09-03 调整） | 技术可行性评估（Android 无 root 注入墙） | 用户真实需求强度是否支持？游戏实时被降级用户接受吗？ |
| 差异化三件套：无广告免费 / 真声克隆 / 低端机流畅 | 竞品观察 | 三者对目标用户的重要性排序与付费归因 |
| 音色市场抽成 + PC 高清订阅（商业模式） | 竞品定价观察 | 付费意愿价格区间 |

### 1.2 研究问题（RQ）

| # | 研究问题 | 对应决策 |
|---|---|---|
| RQ1 | 谁在找变声工具？设备档位、使用场景、频率、当前用什么工具？ | 细分优先级（产品界定 §3 四类） |
| RQ2 | 微信/QQ 语音包、游戏内实时、直播配音三个场景的需求强度排序？主场景调整是否成立？ | MVP 范围 |
| RQ3 | 现用竞品的痛点分布与强度？无广告/真声克隆/低端机流畅的诉求有多强？ | 差异化三件套验证、功能优先级 |
| RQ4 | 愿为什么付费？PSM 可接受价格区间是多少（PC 订阅月费 / 单款音色）？ | 商业模式与定价 |
| RQ5 | 新用户用现有原型（桌面端 + App）能否独立走通核心任务？卡点在哪？ | MVP 接线优先级（微信遥控入口 / 端侧引擎） |

### 1.3 成功标准

- 产出带证据链（引用/数据）的痛点 Top5 与需求排序；
- RQ2-RQ4 每项都有可执行结论（维持/调整主场景、定价区间、功能取舍）；
- 至少 3 条结论直接写进路线图变更。

## 2. 方法总览：三角验证（混合方法）

```
M1 竞品差评挖掘(案头)  ──→ 痛点假设清单 ──┐
                                          ├──→ 交叉验证 ──→ 痛点优先级 → 路线图
M2 问卷(n≥120, 定量)   ──→ 需求分布+付费 ──┤
                                          │
M3 深访(8-12人, 定性)  ──→ 动机与工作流 ──┤
                                          │
M4 可用性测试(5-8人)   ──→ 原型真实卡点 ──┘
```

| 方法 | 回答 | 样本 | 周期 | 成本 |
|---|---|---|---|---|
| M1 竞品差评挖掘 | RQ3 假设生成 | 竞品差评 200-300 条 | 3 天 | ¥0 |
| M2 问卷 | RQ1/RQ2/RQ4 分布 | 有效 n≥120 | 7 天投放 | ¥0 |
| M3 深度访谈 | RQ2/RQ3/RQ4 解释"为什么" | 8-12 人 × 45-60min | 5 天 | ¥30-50/人 |
| M4 可用性测试 | RQ5 | 5-8 人 × 5 任务 | 3 天 | ¥30-50/人 |

**顺序逻辑**：M1 生成假设 → M2 验证分布并筛人 → M3/M4 深挖因果与真实行为。定性与定量结论冲突时，以行为证据（M4）优先于态度证据（M2），深访录音可回溯。

## 3. 招募与筛选

### 3.1 目标人群（对齐产品界定 §3）

| 细分 | 配额（深访/可用性） | 筛选条件 |
|---|---|---|
| A. 微信/QQ 语音社交玩梗用户（核心） | ≥4 人 | 近 1 个月发过变声语音或用过变声 App |
| B. 手游玩家 | 2-3 人 | 月游戏时长 ≥20h，语音开黑 |
| C. 移动主播/短视频创作者 | 2-3 人 | 有变声/配音产出需求 |
| D. 竞品付费用户（对照） | ≥2 人 | 为变声 App 付过费 |

### 3.2 招募渠道（免费优先）

1. **问卷即招募**：问卷末尾留深访报名（送红包），按配额表筛选；
2. 变声相关社群：贴吧（变声器吧/变声）、QQ 群（变声/语音包/配音）、酷安评论区；
3. B 站/小红书变声教程视频评论区私信活跃评论者；
4. 竞品用户：竞品官方群潜水 → 1v1 私信（声明独立研究，非官方）。

### 3.3 排除标准（防偏倚）

- 与开发者认识/有利益关系（可用性测试尤其排除）；
- 从未用过任何变声工具且无场景（留 1-2 名"纯小白"仅用于可用性测试，测首次接触体验）；
- 同一参与者不重复进入多个方法（避免练习效应与意见污染）。

### 3.4 样本量依据

- **问卷 n≥120**：95% 置信水平下整体比例误差 ±9%，方向性结论够用；交叉分析仅在子样本 n≥30 时解读（低于此只算方向信号）。若渠道超预期回收 >200，误差收窄至 ±7%；
- **深访 8-12 人**：同质人群主题饱和通常出现在 8-12 场内（Guest et al., 2006）；执行时逐场复盘，连续 2 场无新主题即停；
- **可用性测试 5-8 人**：5 人可发现约 85% 可用性问题（Nielsen & Landauer）。

## 4. M1：竞品差评挖掘（3 天，¥0）

**对象**：应用商店（华为/小米/OPPO/vivo/应用宝）+ 酷安，竞品清单取自《02_竞品分析》：叮咚、声侠客、变声器管家、Voicemod（Google Play 中文评价）。

**流程**：
1. 每竞品抓 1-3 星差评 50-80 条（共 200-300 条），连同点赞数记入 `docs/product/research/m1_差评编码表.csv`；
2. 开放编码：每条贴 1-3 个痛点标签（首批标签示例：`广告烦` `好音色要钱` `音质假` `延迟大` `操作繁琐` `闪退` `适配差` `克隆不能用`）；
3. 输出：痛点 × 提及频次表 → 转化为问卷李克特题项假设（M2 的题从这来，不拍脑袋）。

**注意**：只记录用户原话标签，不做主观改写；水军刷评（模板句重复）剔除。

## 5. M2：问卷设计（完整题目，可直接投放）

> 平台：腾讯问卷/问卷星。时长控制 ≤5 分钟。逻辑跳转：Q5 选"没用过任何变声工具"→ 结束（进小白池）。

### 甄别与画像（RQ1）
- Q1 年龄段（<18 / 18-24 / 25-30 / 31-40 / 40+）
- Q2 性别
- Q3 常用手机型号（填空，后编码为档位：<1000 / 1000-2000 / 2000-4000 / 4000+）
- Q4 身份：学生 / 上班族 / 自由职业 / 主播 / 其他
- Q5 近 3 个月是否用过变声类工具？（App / PC 软件 / 都用过 / 没用过→终止）

### 使用行为（RQ1/RQ2）
- Q6 用过哪些变声工具？（多选：叮咚/声侠客/变声器管家/Voicemod/其他____）
- Q7 主要使用场景（多选限 2）：微信/QQ 发语音整活 / 游戏开黑变声 / 直播 / 短视频配音 / 恶搞朋友 / 其他____
- Q8 使用频率：几乎每天 / 每周几次 / 每月几次 / 更少
- Q9 最常用 1-2 个什么音色？（预设搞笑音色 / 明星网红音色 / 动漫角色 / 自己克隆的 / 其他____）

### 痛点评级（RQ3，题项来自 M1 编码结果）
- Q10-Q14 五级李克特（1=完全不是问题，5=非常痛）：
  - 广告太多太烦
  - 好听的音色要付费/看广告解锁
  - 变出来的声音假、一听就是软件变的
  - 操作繁琐（录完还要倒来倒去）
  - 低端手机卡顿/发热/闪退
- Q15 开放题：现有工具最让你抓狂的一件事？（原话收集，供 M3 追问）

### 主场景验证（RQ2）
- Q16 以下功能你更想要哪些？（多选限 2）：
  - a 录音/打字→变声语音条→一键发微信/QQ
  - b 手机游戏里说话实时变声
  - c 直播/录屏配音实时变声
  - d 用自己的声音克隆出专属音色
  - e 有声书/长文本配音
- Q17（若选 b）"安卓限制导致手机游戏内注入不可行，但 PC 游戏可以用手机当无线麦实时变声"，你能接受吗？（能 / 不能 / 要看延迟）

### 付费意愿（RQ4）
- Q18 你为变声功能付过费吗？花了多少？
- Q19 PSM 四连（针对"PC 高清变声+真声克隆月订阅"）：
  - 多便宜你会怀疑质量不敢用？____元/月
  - 什么价格你觉得便宜划算？____元/月
  - 什么价格你觉得有点贵但能接受？____元/月
  - 什么价格你觉得太贵绝不买？____元/月
- Q20 单款精选音色（如某个热门角色音色）你觉得一次买断多少元合理？（<3 / 3-6 / 6-12 / 12-25 / 不买单款，要订阅）

### Kano 简化题（RQ3，四特征 × 正反两问）
> 针对四个候选差异化特征，每题两问："如果有这个功能你感觉如何 / 如果没有这个功能你感觉如何"，选项：我很喜欢 / 理所当然 / 无所谓 / 勉强接受 / 我很不满。特征：①真声克隆 ②无广告免费 ③低端机不卡 ④一键发微信。

- Q21-Q28（8 题，按上述模板）

### 招募（衔接 M3）
- Q29 是否愿意参加 45 分钟语音访谈（¥50 红包）？（是→留联系方式 / 否）

## 6. M3：深度访谈提纲（60 分钟脚本）

> 1v1 语音/见面，全程录音（先取得口头+文字授权）。纪律：多问"上次/具体那次"，禁止问"你会用吗/你会买吗"（假想答案无效）；访谈员只追问不评价。

1. **暖场与背景（5min）**：自我介绍、知情同意、录音授权；"说说你平时用声音搞的有趣事"。
2. **最近一次真实经历（15min，行为证据核心）**：
   - "上次你想把一条语音变个声，从头讲一遍，当时在干嘛？"
   - 追问：用的什么工具 → 每一步怎么操作 → 哪一步卡了/烦了 → 最后发出去了吗 → 对方什么反应。
3. **工具与切换（10min）**：现在用什么 → 之前用过什么 → 为什么换（关键：换弃原因=真实痛点）→ 付过钱吗、为什么付/为什么不付。
4. **场景深挖（10min）**：对照其问卷 Q7 答案逐场景问实例；游戏场景重点问"知道手机游戏内变声做不了之后，你的反应/替代办法"。
5. **原型意向探测（10min，出 3 张功能卡，按重要度排序并说理由）**：
   - 卡1：录音/打字→变声→一键发微信；卡2：30 秒录音克隆专属音色；卡3：手机当 PC 无线麦（游戏/直播实时）。
   - "排个序，为什么？哪个你现在就会装来用？哪个可有可无？"
6. **付费心理（5min）**：竞品会员买过吗 → "什么样的东西你才愿意为声音付钱"（问判断标准，不问价格接受度）。
7. **收尾（5min）**："如果只能改进一件事，改什么？" + 补充问题 + 致谢发红包。

**记录模板**（每场一份，`m3_访谈记录_编号.md`）：参与者编号/细分/设备档 → 关键引用原话（≥5 条）→ 行为流程图（步骤×情绪↑↓）→ 新出现的主题标签。

## 7. M4：可用性测试方案

> 对象：5-8 人（含 1-2 名未用过变声工具的小白）。环境：参与者自带手机 + 测试用 PC（装好桌面端与后端）。录屏 + 录音。全程 think-aloud："想到什么说什么"。

### 任务卡（对齐 App 真实四 Tab 与桌面端）

| # | 任务（按原文读给参与者） | 成功标准 | 观测重点 |
|---|---|---|---|
| T1 | "你的手机要连上电脑上的变声程序，你试试。" | 主控台显示后端在线 | 配对引导是否自明；host/Key 填写卡点 |
| T2 | "录一段你说的话，把它变成'袋鼠骑士'的音色，听听效果。" | 完成录音→变声→播放 | 离线变声参数（pitch/index_rate）是否吓退用户 |
| T3 | "打字让'袋鼠骑士'帮你念出来，并把这条语音发到你自己的微信上。" | 合成→分享/发送成功 | TTS Tab → 分享链路完整性；中途放弃点 |
| T4 | "看看音色库，挑一个你觉得'靠谱'的音色，说出理由。" | 能读懂来源/QC 徽标 | 市场/自训标识、试听→安装路径是否被理解 |
| T5 | （PC 侧）"把变声后的声音设置成你的麦克风。" | 理解 VB-CABLE 切换 | 虚拟声卡概念的认知负担 |

### 度量

- 每个：独立完成率 / 无协助完成率 / 用时 / 求助次数 / 错误次数 / 放弃点；
- 全场后做 **SUS 量表**（10 题标准版，0-100 分；行业均值 ≈68，<68 为低于平均）；
- 赛后访谈 10min："最爽的一步 / 最想砸手机的一步 / 回家还会用吗，为什么"（记录，不作承诺依据）。

## 8. 数据分析计划（结果回收后按此执行）

> 以下为分析框架与报告模板。**数据未采集前不预设任何结论**；本节所有表格为待填模板。

### 8.1 定量分析（M2）

| 分析 | 方法 | 输出 |
|---|---|---|
| 画像分布 | 频数表 | 用户画像饼图（RQ1） |
| 痛点强度 | Q10-14 均值 × 打 4-5 分占比，双指标排序 | 痛点 Top5 表 |
| 场景排序 | Q16 各项选择率（多选限 2 → 去重占比可比） | 场景需求排序（RQ2） |
| 交叉分析 | 设备档 × 场景 / 身份 × 付费，仅子样本 n≥30 时解读 | 细分差异表 |
| Kano 分类 | 每特征按正反两问组合映射 M/O/A/I/R/Q；计算 Better=(¬A∧¬R 总和)，Worse=−(M+R)/(M+R+O+I) | Better-Worse 四象限图 → 功能属性判定 |
| 定价 | PSM：四条累计曲线交点 → 可接受价格区间 [OPP, IPP] 与 无差异点 P0 | 订阅定价建议区间 |

### 8.2 定性分析（M1/M3）

- 转录后**开放编码** → 亲和图聚类 → 主题（目标：每方法收敛 ≤8 个主题）；
- 主题表模板：主题 | 定义 | 证据引用数 | 来源参与者编号 | 与 M1 假设的关系（印证/推翻/新增）；
- M1 与 M3 编码表对齐后做**三角验证**：某痛点需 ≥2 个方法独立出现才进 Top5（单一来源标注为"待验证信号"）。

### 8.3 研究结论报告模板（`06_用户研究报告_声迅VoxLink.md`）


## 10. 伦理与合规

1. **知情同意**：深访/可用性测试前说明目的、录音用途、可随时退出；书面（聊天记录截图即算）+ 口头双确认；
2. **匿名化**：报告只用编号（P01-P12），联系方式与录音仅本地存储，报告完成后录音按参与者意愿删除；
3. **未成年人**：<18 岁需监护人同意，否则排除；
4. **产品红线前置**：招募话术与访谈中声明——本产品仅支持克隆本人/已授权/虚构角色声音，研究者不引导参与者谈论冒用他人声音的用途；
5. **竞品潜水礼仪**：私信声明独立研究身份，不冒充官方、不拉踩。
