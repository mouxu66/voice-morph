# 潮汕话起步（潮州）· 2026-10-21

> 定位：**研究用途，不做商用**。所以 NC 语料可用、可以发论文/发权重，但不能用于商业分发。
> 目标：先把「潮州话 → 文字」这一环做出**可复现的基线**，再接回现有的
> 普通话 TTS + RVC，得到「方言进、我的音色出」。

## 1. 为什么先固定「潮州」，不是笼统的「潮汕」

潮汕话内部至少分潮州、汕头、揭阳、潮阳几片，声调和用词都有差别。混着录、混着评，
CER 会变成几种口音的平均值，**既不能指导模型也不能复现**。第一步只做驻地这一种，
另外几片等第一版基线稳定后再单独测。

## 2. 数据从哪来

| 来源 | 规模 | 许可 | 现状 |
|---|---|---|---|
| **Teochew-Wild**（`panlr/teochew_wild`） | 18.9h / 12,500 句 / 20 人；正字 + 潮汕拼音 | **CC BY 4.0**（HF API 直读确认） | **gated: manual** —— 必须用 HF 账号申请 |
| WenetSpeech-Min | ~10,000h 闽南语（2026-09） | 待核 | 大语料，做对照/预训练参考 |
| 自采 dev 集 | 30 句起，1–3 人 | 本人/家属授权 | **不依赖上面任何一条，今天就能做** |

⚠️ 申请 gated 数据集请走官方流程，**不要用镜像绕**（作者设了门槛，绕过既不合适也不稳定）。

## 3. dev 集怎么录（W1，先做这个）

**规格**：30 句，每句 3–8 秒，同一个人、同一部手机、同一间安静房间；16kHz 以上；
不降噪、不压缩、不加混响；峰值 ≤ −6dBFS；句间停 1 秒。

**内容**：下面每类 3 句，用**潮州话自然说出**（不要念书面普通话再硬转）：

| 类别 | 例子（用潮州话说） |
|---|---|
| 数字/时间 | 「三点半我来接你」「初八那天很热」 |
| 亲属称谓 | 「阿妈叫我返来食饭」「伊是阮阿舅」 |
| 食物 | 「今晚煮糜配咸菜」「这碗粿条太咸」 |
| 地名/方位 | 「物件放在桌顶」「去牌坊街怎么行」 |
| 日常动作 | 「衫裤收了没」「门锁好未」 |
| 疑问句 | 「汝食饱未？」「做呢无来？」 |
| 句末语气词 | 「好啦」「是啊咧」「猛猛来」 |
| 入声/短促字 | 「十」「白」「食」「落」各造一句 |
| 长句（>6s） | 讲一件今天发生的事，20–30 字 |
| 数字串/人名 | 报一个电话号码、一个本地人名 |

**每条都要有一条普通话对照**（你自己写，不用标准答案）：评测只比字，不比发音。

**落盘**：`media/teochew/dev/<speaker>/<take>.wav` + `manifest.jsonl`：

```json
{"wav": "media/teochew/dev/mx/001.wav", "text": "三点半我来接你", "speaker": "mx", "region": "chaozhou", "take": 1}
```

## 4. 评测口径（别让假绿骗自己）

1. **简繁归一**：whisper 在 `language=zh` 下默认出繁体（本机实测「但現有方法門檻太高用不上」）。
   不归一化，一句完全正确的话会凭空多出 25% 错字。
2. **标点/空白不计**；方言字（阮/厝/食/汝）必须保留。
3. **按说话人切分**，不按句随机切 —— 20 个说话人的语料，按句切会让同一个人横跨 train/test。
4. **ASR 调用要带** `initial_prompt="以下是简体中文。\n"`（与 `qwen3_tts_service.py` 一致），
   归一化是第二道保险。
5. 报告三个数：**CER（字）**、**可懂度（人听 1–5）**、**内容保真**（有没有把意思改掉）。

工具：`m2_server/asr_eval.py`

```bash
# 按说话人切分（2 人 eval / 2 人 dev / 其余 train），并检查 wav 是否存在
.venv/Scripts/python.exe m2_server/asr_eval.py \
  --manifest media/teochew/dev/manifest.jsonl \
  --split-out outputs/teochew/split.json --n-eval 1 --n-dev 1 --check-files
```

## 5. 里程碑与停止条件

| 周 | 做什么 | 验收 |
|---|---|---|
| W1 | 申请 gated；录 30 句 dev；whisper-small 零样本（带 prompt） | 基线 CER 有数（预期很差，>60% 也算数） |
| W2 | Teochew-Wild 到手：核对正字口径、按人切分 | 切分可复现、无说话人泄漏 |
| W3 | whisper-medium LoRA vs Dolphin-CN-Dialect 0.4B（闽南 token，流式） | speaker-disjoint CER 目标 <15% |
| W4 | 正字 → 普通话规范化 → Qwen3-TTS → RVC | 可懂度/内容/音色三项都有数 |

**停止条件**：speaker-disjoint CER >25% → 18.9h 不够，退成「粤语/四川话跑管线 + 潮汕只做声音档案」；
显存不够 medium LoRA → 只用 whisper-small LoRA 或 Dolphin，别硬上 large。

## 6. 许可红线（研究可以，商用不行）

## 7. 2026-10-22 修订：顺序反过来 —— 先 TTS，ASR 直接借现成的

> §5 那张 W1→W4 把三周压在"自己做潮汕话 ASR 基线"上。改这一节的理由是：
> 那件事**已经有人用同一个数据集做完了**，而 TTS 那边是空的。

### 7.1 ASR 已有人做到 §5 的验收线

| 已有成果 | 训练口径 | 指标 | 来源 |
|---|---|---|---|
| `panlr/whisper-finetune-teochew` | whisper-medium，teochew_wild 11000/700/700 | 正字 CER **12.25%**（test）/ 12.87%（val） | 📚 HF 模型卡 |
| Teochew-Wild 论文实验 | whisper-medium 微调 | CER **10.01%** | 📚 论文 |
| `efficient-nlp/teochew-whisper-medium` | 35h **自动字幕**粗数据（反例） | WER 0.31 清晰 / 0.68 对话 | 📚 HF |

⚠️ **12.25% 不能直接采信**：模型卡写明"随机划分训练/验证/测试"，即**按句随机**，
同一个人同时落在 train 和 test —— 正是本文件 §4 第 3 条禁止的说话人泄漏。
真实 speaker-disjoint CER 会明显更高。**可以当 baseline，不能当结论。**

→ 动作：直接下这个权重，用本机 30 句 dev 集按人重测一次。
CER 落在 15% 内就用它接翻译；崩到 25% 以上再谈自己训。
一周内能拿到数，不必占三周。

### 7.2 TTS 是真正的空白

检索未见任何公开的潮汕话 TTS 权重。Teochew-Wild 论文只做了 Tacotron2 实验
（MOS 3.52 / 5），**未发布模型**（❓未见发布，非断言不存在）。
而本项目已有：Qwen3-TTS 1.7B + QLoRA 微调（`tts_trial/sft_8gb.py`）、RVC、
微信一键发送、A-B 盲听（`ab_api.py` / `blindtest_api.py`）。
**工程链条全齐，只缺语言能力。**

→ 结论：**TTS 是唯一必须自己做、也唯一还没人在前面做完的事。**

### 7.3 两个目标 = 同一个正字底座的两条边

```
目标 A（文字出声音）  普通话文字 ──LLM 改写──▶ 潮汕正字 ──┬──▶ TTS ──▶ 语音
目标 B（声音出文字）  潮汕话音 ──ASR 正字──▶            │
                                                      └──▶ LLM 翻译 ──▶ 普通话
```

正字是唯一共享的枢纽。所以 §1「先固定潮州」这个判断仍然成立 —— 只是它服务的是
**正字口径统一**，不只是 CER 可比。

### 7.4 TTS 的输入走拼音，不走汉字（待 A-B 裁决）

三个理由：

1. **生僻字与自造字**。Teochew-Wild 用的是"歹看正字法"（用「祇」代「这」、用「介」代「的」），
   这类字在 Qwen tokenizer 里语法上存在，但带着普通话先验（"祇"=qí，地神）。
   微调能覆盖，要多花数据。
2. **声调是命脉**。潮汕话 8 个调 + 连读变调。拼音 `i1 zi2 gai5 nang5` 把声调用数字直接编码，
   汉字做不到；G2P 生成时也不会丢。
3. **无多音字歧义**。Teochew-Wild 自己就记着"单字最多四种发音变体"，
   拼音串是唯一解，汉字串是多解。

代价：序列变长、词边界丢失（靠空格分隔音节缓解）、韵律预测可能崩。
**所以这不是拍板，是待测假设** —— 用现成的 A-B 盲听跑「汉字输入 vs 拼音输入」两臂，
按可懂度 + 自然度定，别靠推理定。

### 7.5 你自己是母语者，就不需要 RVC

§5 的 W4 写着"路：正字 → 普通话规范化 → Qwen3-TTS → **RVC**"。
如果 TTS 的训练数据就录你自己的声音（`media/teochew/dev/<speaker>/`，speaker=mx），
训出来的天然是你的音色，**RVC 那一段可以整段删掉**。

RVC 只有在"用别人的音色说潮汕话"时才需要。这既省一道失真，
也是产品上的差异点：**我的音色会说潮汕话**，不是"一个潮汕人声音 + 再套我的壳"。

数据配比建议（两阶段，别一锅炖）：
- 阶段一：Teochew-Wild 18.9h 全量，学"字音映射 + 变调"，不管音色；
- 阶段二：自己 1–2h（`dev` 30 句只是评测，训练要另录），收音色。
- 两阶段都比"混在一起一次性微调"更容易判断是哪一段没学好。

### 7.7 修订后的顺序

| 步 | 做什么 | 判据 |
|---|---|---|
| 1 | 跑 `panlr/whisper-finetune-teochew`，本机 dev 集按人重测 | CER 有数；≤15% 进第 4 步 |
| 2 | Teochew-Wild 到手后转拼音输入格式，QLoRA 微调 Qwen3-TTS | 能听懂（可懂度 ≥3/5） |
| 3 | 汉字臂 vs 拼音臂 A-B 盲听 | 定下 TTS 输入口径 |
| 4 | 接 `teochew_fe.py`：普通话 → 正字 → 拼音 → TTS | 一句话端到端出声 |
| 5 | ASR 输出正字 → LLM 翻译 → 普通话 | 目标 B 通 |

**第 1 步今天就能做，不依赖 gated 申请**（权重公开，dev 集自己录）。
第 2 步才卡 Teochew-Wild 的审批。
