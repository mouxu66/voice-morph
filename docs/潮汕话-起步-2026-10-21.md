# 潮汕话起步（潮州）· 2026-10-21

> 定位：**研究用途，不做商用**。所以 NC 语料可用、可以发论文/发权重，但不能用于商业分发。
> 目标：先把「潮州话 → 文字」这一环做出**可复现的基线**，再接回现有的
> 普通话 TTS + RVC，得到「方言进、我的音色出」。

## 1. 为什么先固定「潮州」，不是笼统的「潮汕」

潮汕话内部至少分潮州、汕头、揭阳、潮阳几片，声调和用词都有差别。混着录、混着评，
CER 会变成几种口音的平均值，**既不能指导模型也不能复现**。第一步只做驻地这一种，
另外几片等第一版基线稳定后再单独测。

## 3. ~~dev 集怎么录（W1，先做这个）~~ → **已作废，见 §8.2**

> 2026-10-22：本人非母语者，录不出潮汕话 dev 集。本节保留只因录音规格本身仍有参考
> 价值（将来若找到母语者补录自采集时照此执行）。

**规格**：30 句，每句 3–8 秒，同一个人、同一部手机、同一间安静房间；16kHz 以上；
不降噪、不压缩、不加混响；峰值 ≤ −6dBFS；句间停 1 秒。

**内容**：下面每类 3 句，用**潮州话自然说出**（不要念书面普通话再硬转）：

| 类别 | 例子（用潮州话说） |
|---|---|
| 数字/时间 | 「三点半我来接你」「初八那天很热」 |
| 亲属称谓 | 「阿妈叫我返来食饭」「伊是阮阿舅」 |
| 食物 | 「今晚煮糜配咸菜」「这碗粿条太咸」 |
| 地名/方位 | 「物件放在桌顶」「去牌坊街怎么行」 |
| 日常动作 | 「衫裤收了没」「门锁好未」 |
| 疑问句 | 「汝食饱未？」「做呢无来？」 |
| 句末语气词 | 「好啦」「是啊咧」「猛猛来」 |
| 入声/短促字 | 「十」「白」「食」「落」各造一句 |
| 长句（>6s） | 讲一件今天发生的事，20–30 字 |
| 数字串/人名 | 报一个电话号码、一个本地人名 |

**每条都要有一条普通话对照**（你自己写，不用标准答案）：评测只比字，不比发音。

**落盘**：`media/teochew/dev/<speaker>/<take>.wav` + `manifest.jsonl`：

```json
{"wav": "media/teochew/dev/mx/001.wav", "text": "三点半我来接你", "speaker": "mx", "region": "chaozhou", "take": 1}
```

## 4. 评测口径（别让假绿骗自己）

1. **简繁归一**：whisper 在 `language=zh` 下默认出繁体（本机实测「但現有方法門檻太高用不上」）。
   不归一化，一句完全正确的话会凭空多出 25% 错字。
2. **标点/空白不计**；方言字（阮/厝/食/汝）必须保留。
3. **按说话人切分**，不按句随机切 —— 20 个说话人的语料，按句切会让同一个人横跨 train/test。
4. **ASR 调用要带** `initial_prompt="以下是简体中文。\n"`（与 `qwen3_tts_service.py` 一致），
   归一化是第二道保险。
5. 报告三个数：**CER（字）**、**可懂度（人听 1–5）**、**内容保真**（有没有把意思改掉）。

工具：`m2_server/asr_eval.py`

```bash
# 按说话人切分（2 人 eval / 2 人 dev / 其余 train），并检查 wav 是否存在
.venv/Scripts/python.exe m2_server/asr_eval.py \
  --manifest media/teochew/dev/manifest.jsonl \
  --split-out outputs/teochew/split.json --n-eval 1 --n-dev 1 --check-files
```

## 5. 里程碑与停止条件

| 周 | 做什么 | 验收 |
|---|---|---|
| W1 | 申请 gated；录 30 句 dev；whisper-small 零样本（带 prompt） | 基线 CER 有数（预期很差，>60% 也算数） |
| W2 | Teochew-Wild 到手：核对正字口径、按人切分 | 切分可复现、无说话人泄漏 |
| W3 | whisper-medium LoRA vs Dolphin-CN-Dialect 0.4B（闽南 token，流式） | speaker-disjoint CER 目标 <15% |
| W4 | 正字 → 普通话规范化 → Qwen3-TTS → RVC | 可懂度/内容/音色三项都有数 |

**停止条件**：speaker-disjoint CER >25% → 18.9h 不够，退成「粤语/四川话跑管线 + 潮汕只做声音档案」；
显存不够 medium LoRA → 只用 whisper-small LoRA 或 Dolphin，别硬上 large。

## 7. 2026-10-22 修订：顺序反过来 —— 先 TTS，ASR 直接借现成的

> §5 那张 W1→W4 把三周压在"自己做潮汕话 ASR 基线"上。改这一节的理由是：
> 那件事**已经有人用同一个数据集做完了**，而 TTS 那边是空的。

### 7.1 ASR 已有人做到 §5 的验收线

| 已有成果 | 训练口径 | 指标 | 来源 |
|---|---|---|---|
| `panlr/whisper-finetune-teochew` | whisper-medium，teochew_wild 11000/700/700 | 正字 CER **12.25%**（test）/ 12.87%（val） | 📚 HF 模型卡 |
| Teochew-Wild 论文实验 | whisper-medium 微调 | CER **10.01%** | 📚 论文 |
| `efficient-nlp/teochew-whisper-medium` | 35h **自动字幕**粗数据（反例） | WER 0.31 清晰 / 0.68 对话 | 📚 HF |

⚠️ **12.25% 不能直接采信**：模型卡写明"随机划分训练/验证/测试"，即**按句随机**，
同一个人同时落在 train 和 test —— 正是本文件 §4 第 3 条禁止的说话人泄漏。
真实 speaker-disjoint CER 会明显更高。**可以当 baseline，不能当结论。**

→ 动作：直接下这个权重，用本机 30 句 dev 集按人重测一次。
CER 落在 15% 内就用它接翻译；崩到 25% 以上再谈自己训。
一周内能拿到数，不必占三周。

### 7.2 TTS 是真正的空白

检索未见任何公开的潮汕话 TTS 权重。Teochew-Wild 论文只做了 Tacotron2 实验
（MOS 3.52 / 5），**未发布模型**（❓未见发布，非断言不存在）。
而本项目已有：Qwen3-TTS 1.7B + QLoRA 微调（`tts_trial/sft_8gb.py`）、RVC、
微信一键发送、A-B 盲听（`ab_api.py` / `blindtest_api.py`）。
**工程链条全齐，只缺语言能力。**

→ 结论：**TTS 是唯一必须自己做、也唯一还没人在前面做完的事。**

### 7.3 两个目标 = 同一个正字底座的两条边

```
目标 A（文字出声音）  普通话文字 ──LLM 改写──▶ 潮汕正字 ──┬──▶ TTS ──▶ 语音
目标 B（声音出文字）  潮汕话音 ──ASR 正字──▶            │
                                                      └──▶ LLM 翻译 ──▶ 普通话
```

正字是唯一共享的枢纽。所以 §1「先固定潮州」这个判断仍然成立 —— 只是它服务的是
**正字口径统一**，不只是 CER 可比。

### 7.4 TTS 的输入走拼音，不走汉字（待 A-B 裁决）

三个理由：

1. **生僻字与自造字**。Teochew-Wild 用的是"歹看正字法"（用「祇」代「这」、用「介」代「的」），
   这类字在 Qwen tokenizer 里语法上存在，但带着普通话先验（"祇"=qí，地神）。
   微调能覆盖，要多花数据。
2. **声调是命脉**。潮汕话 8 个调 + 连读变调。拼音 `i1 zi2 gai5 nang5` 把声调用数字直接编码，
   汉字做不到；G2P 生成时也不会丢。
3. **无多音字歧义**。Teochew-Wild 自己就记着"单字最多四种发音变体"，
   拼音串是唯一解，汉字串是多解。

代价：序列变长、词边界丢失（靠空格分隔音节缓解）、韵律预测可能崩。
**所以这不是拍板，是待测假设** —— 用现成的 A-B 盲听跑「汉字输入 vs 拼音输入」两臂，
按可懂度 + 自然度定，别靠推理定。

### 7.5 ~~你自己是母语者，就不需要 RVC~~ → **已被 §8.1 推翻**

§5 的 W4 写着"路：正字 → 普通话规范化 → Qwen3-TTS → **RVC**"。
如果 TTS 的训练数据就录你自己的声音（`media/teochew/dev/<speaker>/`，speaker=mx），
训出来的天然是你的音色，**RVC 那一段可以整段删掉**。

RVC 只有在"用别人的音色说潮汕话"时才需要。这既省一道失真，
也是产品上的差异点：**我的音色会说潮汕话**，不是"一个潮汕人声音 + 再套我的壳"。

数据配比建议（两阶段，别一锅炖）：
- 阶段一：Teochew-Wild 18.9h 全量，学"字音映射 + 变调"，不管音色；
- 阶段二：自己 1–2h（`dev` 30 句只是评测，训练要另录），收音色。
- 两阶段都比"混在一起一次性微调"更容易判断是哪一段没学好。

## 8. 2026-10-22 追加：非母语者约束（推翻 §7.5 与 §5 的录音计划）

> 用户明确："我不是母语者，我不会，我无法提供这部分的素材。"
> 这条约束**同时推翻两处**：§7.5「不需要 RVC」作废；§3「录 30 句 dev」作废。

### 8.1 修正一：RVC 必须恢复，而且更要紧

§7.5 判定"训练数据录本人声音 → RVC 可删"。前提是本人会说潮汕话，**不成立**。
本人只能提供**普通话**录音，而 RVC 学的是音色、不是语言 —— 所以：

```
普通话文字 → LLM 改写 → 潮汕正字 → pyPengIm 拼音 → TTS（潮汕音色）→ RVC（我的音色）→ 微信
```

RVC 那段**回到 §5 W4 的原样**，且新增一个待验风险：**跨语言 RVC**。
源音频是潮汕话（未见语言的音素分布），target 是普通话训的音色包，
hubert 特征对源语言越不熟，音色迁移越容易失真。需实测，别预设能work。
（本机已有 `rvc_live.py` / `offline_vc.py` / `make_rvc_dataset.py`，改的是数据集来源不是代码。）

### 8.2 修正二：dev 集改为 Teochew-Wild 按人切分，不自己录

无母语能力 → 录不出潮汕话 dev 集。改为：20 个说话人里留 2–3 人做 dev/test，
其余入 train。这正是 `asr_eval.py --split-out --n-eval 1 --n-dev 1` 在做的事，
`manifest.jsonl` 从 `teochew_wild/annotation/annotation.txt` 直接转，不用自己攒。

### 8.3 「网上教育者的有字幕视频」能不能用：分两类，只有一类能训 TTS

| 视频类型 | 字幕实质 | 能训 TTS？ | 能训改写/翻译？ |
|---|---|---|---|
| 潮汕话**教学**（教发音/正字/拼音） | 可能真是正字或拼音 | ✅ 可以，但要核字幕口径 | ✅ |
| 潮汕话讲古 / 新闻 / 影视（带普通话字幕） | **意译**（「汝食饱未」打「你吃饭了吗」） | ❌ **教坏，即文本-音素错位** | ✅ 正好 |
| 无字幕 | — | 需先 ASR + 母语者校对 | ❌ |

**「有字幕」≠「字幕可信」** —— 传播类字幕是为观众看懂而做的意译，不是逐字转写。
所以这类素材的默认判定是：**能训翻译，不能训 TTS。**
要判定一条素材属于哪种，抽 5 句比对：把音频里听到的音节（用 pyPengIm 或
Teochew-Wild 的标法记下）和字幕逐字对一遍，**能对上字音边界的才是正字**。

### 8.4 但这条路的成本远高于直接用 Teochew-Wild

Teochew-Wild 的原始来源就是「民生新闻、潮汕讲古、地方电视节目、抖音自媒体口播」
（📚 数据集 README）—— **正是用户打算去扒的那批视频**。作者已经把
「切分 → 降噪 → 正字 + 拼音标注」做完了，18.9h / 12,500 句 / 20 人，CC BY 4.0。

自己重做一遍的增量：多花几十小时标注，得到一份更小、标注更差的副本。
→ 结论：**别重做。要特定音色时，用 §8.5 的短参考音路线。**

### 8.5 音色从哪来（三条路，按风险排序）

| 路 | 做法 | 素材量 | 风险 |
|---|---|---|---|
| A | Teochew-Wild 20 人里挑一个 | 已有 | 无。但不是"我的"音色 |
| B | TTS(潮汕音色) → RVC(普通话训的我的音色包) | 我的普通话录音，已有 | 跨语言失真，需实测（§8.1） |
| C | zero-shot 克隆某个教育者/UP 主音色 | 10–30s | **版权**。本仓库 AGENTS.md「袋鼠音色素材铁律」第 2 条已立过同类红线：第三方下载素材不进训练集。别开这个口子 |

### 8.6 作者本人的诚实评价（预期管理）

> "目前 teochew 的数据时长不到 19 个小时，仍然有许多「潮汕土语」没有覆盖，
> **所以实际应用效果也一般**。" —— `AI_for_Teochew` README（📚 原话）

配合 §7.1 的 12% CER 与 §7.2 的 MOS 3.52，三条口径指向同一件事：
**19h 能做出"可复现的基线"，做不出"能商用/能发朋友圈"的效果。**
别把第一版当成品。

### 8.7 一条硬约束：评测必须有母语者

用户不懂潮汕话，**"可懂度 1–5"这一项本人给不出分**。可用的替代只有两种：

1. **ASR 回环**：合成音频 → `panlr` 模型 → 比对输入拼音/正字。
   能自动跑、能看趋势，但 ASR 本身 CER 12%，**只能当粗筛，不能当验收**。
2. **母语者抽听**：家属/朋友，一轮 20 句、盲听、只判"听不听得懂"。
   `blindtest_api.py`（手机扫码盲听打分）现成，把页面发过去就行。

→ 这条不解决，后面所有"效果变好了"的判断都没有依据。**先定人，再开训。**

### 8.8 顺带记两条可借的现成件

- **潮州话 BigVGAN 声码器**已公开（22k / 24k，555h 微调，DNSMOS 3.1038 ≈ GT 3.1040），
  📚 `panlr/BigVGAN_22khz_teochew`。走 mel + Tacotron2/VITS 路线时直接省掉"训声码器"
  这一大块；走 codec-based（Qwen3-TTS）路线用不上。
- **负面结果别重犯**：LREC-COLING 2024《Can Taiwanese Help?》试过
  「台湾闽南语句级 + 潮汕字词级」混合训练，📚 因两地差别过大**未成功**。
  别拿台湾闽南语数据顶潮汕话。

### 9.3 跨语言 RVC 首测 ✅

源：上述视频 3 段人声（**女声**，pyin f0 中位 235–251Hz）。
目标：`myvoice_ppt12_full.pth` + `added_IVF817...index`（用户自己的音色包）。
调用 `m2_server/offline_vc_infer.py`，seed=1234。

| 输入 | 处理 | CAM++ 与参考音余弦 |
|---|---|---|
| 潮汕话源（女声，未转换） | — | −0.018 |
| t00（4.7s） | pitch **−12** | **0.640** |
| t01（3.9s） | pitch **−12** | **0.670** |
| t02（3.9s） | pitch **−12** | **0.657** |
| t00（4.7s） | pitch **0**（对照） | 0.455 |

**三条读数：**

1. **跨语言 RVC 不是"能不能"，是"掉多少"**。0.64–0.67 说明音色确实转过去了，
   比源音频的 −0.018 判若两人；但同语言（普通话）走同一套音色包的历史基线是
   **0.784 → 0.846**（`media/ft_work/ppt12/myvoice_rvc_full/eval.json`），
   这轮比它低约 **0.18**。
2. **这 0.18 不能全记在"跨语言"账上**。本轮同时变了三个量：语言、性别（女→男）、
   音源质量（视频音轨，156k m4a）。要拆开必须补一组**同性别跨语言**对照
   （潮汕话男声源）或**同语言跨性别**对照（普通话女声源 → −12）。
   **没拆之前，"跨语言损失 0.18"是错的写法。**
3. **降八度是硬要求**。不变调 0.455 vs 降八度 0.64–0.67，差一截且音色基本没过来。
   以后女声源固定 `−12`，别试 `0`。

听感页：`media/teochew/_probe/listen.html`（含原始音 + 4 条转换，带分数）。

| 用途 | 判定 | 依据 |
