# 前端自动构建 - 完整使用指南

## 🚀 三种启动方式（推荐程度从高到低）

---

## ⭐⭐⭐⭐⭐ 方式一：应用内一键启动（最方便）

**正在开发中...** 

未来版本会在应用设置里添加"启用自动构建"开关，打开后应用会自动启动监听器。

---

## ⭐⭐⭐⭐ 方式二：双击批处理文件（强烈推荐）

在项目根目录创建快捷方式：

### 步骤 1：创建快捷方式
```
D:\变声\start-watch-ship.bat
```

### 步骤 2：发送到桌面快捷方式
1. 右键点击 `start-watch-ship.bat`
2. 选择"发送到" → "桌面快捷方式"

### 步骤 3：每次开发前双击桌面图标
```
══════════════════════════════════════
   前端自动构建监听器 - 变声工坊
══════════════════════════════════════

👀 正在启动文件监听服务...
💡 提示：保持此窗口运行，修改前端代码后会自动构建
```

**优点：**
- ✅ 无需打开 PowerShell
- ✅ 只需双击一下
- ✅ 自动进入项目目录
- ✅ 中文界面更友好

---

## ⭐⭐⭐ 方式三：手动输入命令（当前方案）

```bash
cd web
npm run watch-ship
```

**缺点：**
- ❌ 需要打开 PowerShell
- ❌ 需要记住命令
- ❌ 需要切换目录

## 💡 推荐工作流程

### 日常开发流程

```
┌─────────────────────────────────────┐
│ 1. 双击桌面快捷方式                  │
│    start-watch-ship.bat             │
│    ↓                                │
│ 2. 终端开始监听                      │
│    👀 正在监听 web/src/ ...         │
│    ↓                                │
│ 3. 在 VS Code 中修改代码              │
│    (编辑器独立运行)                   │
│    ↓                                │
│ 4. 保存文件                         │
│    ↓                                │
│ 5. 监听器自动检测并构建               │
│    📝 检测到文件变化                │
│    ⏱️  等待 2 秒防抖                 │
│    🚀 执行 npm run build           │
│    ✅ 构建完成！                    │
│    ↓                                │
│ 6. 完全退出应用并重启                 │
│    (查看新效果)                      │
└─────────────────────────────────────┘
```

### 一次配置，长期使用

只需要：
1. **首次设置**：双击 `start-watch-ship.bat` 一次
2. **后续开发**：每次打开电脑时双击桌面图标即可
3. **关闭时**：在终端按 `Ctrl+C` 或关闭窗口

## 🔧 高级用法

### 仅构建模式（不同步到安装版）

```bash
npm run watch-ship -- --dev
```

适合快速测试构建是否成功，不需要每次都同步到应用。

### 后台静默运行（可选）

如果不想看到命令行窗口，可以创建 `.vbs` 脚本隐藏窗口：

**`start-watch-ship-hidden.vbs`:**
```vbs
Set oWShell = CreateObject("WScript.Shell")
oWShell.Run chr(34) & "D:\变声\start-watch-ship.bat" & Chr(34), 0, False
Set oWShell = Nothing
```

双击这个 `.vbs` 文件会在后台运行，不会显示窗口。
