# 调研报告：文字 → 变声语音 → 发送微信语音消息（非文件）

> 日期：2026-08-31
> 前提：你的微信是最新版（4.1.7+），暂不接受 Hook 封号风险
> 结论先行：**有低风险方案，且与项目现有虚拟声卡架构完美契合，推荐采用**

## 二、关键发现：微信电脑版 4.1.7+ 官方支持发语音消息

2026 年 2 月微信 4.1.7 上线了 PC 端语音消息功能：

- 聊天窗口点输入框左侧**麦克风图标**，或按 **Ctrl + Win** 触发录音；
- **无需按住**：点一下开始录音，再操作结束，比手机版更利于自动化；
- 录音从**系统默认麦克风设备**采集 → 微信自己编码成 silk 发送；
- 快捷键可在 设置→快捷键 自定义。

**这意味着：只要让系统"麦克风"变成 CABLE Output（项目已有脚本），在微信里播放我们的 wav，微信录到的就是变声后的声音，发出去就是真正的语音消息。** 全程不 Hook、不注入、不碰微信内部协议，封号风险与正常使用无异。

## 三、四条路线对比

| 路线 | 原理 | 微信版本 | 真语音消息? | 封号风险 | 结论 |
|---|---|---|---|---|---|
| **A. 官方录音入口 + 虚拟声卡（UI 自动化）** | 麦克风切到 CABLE Output → 用 `uiautomation` 操控微信点击麦克风/发快捷键 → 播放 TTS 音频 → 停止并发送 | 最新版 4.1.7+ ✅ | ✅ 真·语音消息 | 极低（模拟人手操作） | **⭐ 推荐** |
| B. wcferry（Hook 注入） | DLL 注入微信进程，`SendVoice` 直接发 silk | 仅 3.9.11.25 老版，**不支持你的 4.x** | ✅ | 高 | 与你环境不兼容，排除 |
| C. wxauto / wx4py（UI 自动化库） | UIAutomation 桌面自动化 | wxauto 偏 3.9.x；wx4py 支持 4.x | ❌ 只能发文本/文件 | 低 | 发不了语音消息，可借鉴其 UI 自动化写法 |
| D. 协议号/第三方付费 API | 逆向协议 + silk 上传 | 无关客户端 | ✅ | 极高（异地登录设备特征） | 排除 |

### 路线 A 详细流程（拟实现）

```
网页输入文字 → POST /api/wechat/send_voice
  ├─ 1. TTS 合成（袋鼠音色）→ outputs/tts_*.wav     [已有能力]
  ├─ 2. audio_config.ps1 apply 把默认麦克风切到 CABLE Output [已有能力]
  ├─ 3. uiautomation 找到微信聊天窗口（指定联系人），触发录音（麦克风按钮 / Ctrl+Win）
  ├─ 4. 用 sounddevice 向 CABLE Input 播放 wav（微信同时从 CABLE Output 录）
  ├─ 5. 播放完毕 → 结束录音（微信自动发送或再点一次发送）
  └─ 6. 还原系统默认麦克风
```

需要新增的代码：
1. `m2_server/wechat_voice.py`：新模块，封装 UI 自动化（找窗口、点麦克风、结束录音）+ 音频播放到 CABLE；
2. `server.py` 加一个端点 `POST /api/wechat/send_voice`（参数：text / voice_id / 接收人）；
3. 前端 TTS 页加"发送到微信"按钮（或独立微信页）。

### 路线 A 的风险与不确定性（实现时需实测）

- ⚠️ 微信录音**防回采**：部分版本会主动过滤"循环回来的声音"（检测到采集设备是虚拟声卡可能拒绝录音或录出静音）。需实测 4.1.x 行为；若被过滤，备选方案是**真麦播放→手机/另一设备录**（体验差）或 CABLE + 混音卡。
- ⚠️ 录音起始/结束与音频播放的**时序对齐**（早启动≈静音头，需留 200ms 缓冲）。
- ⚠️ UI 自动化要求微信窗口可被定位（可最小化，不必前台置顶也可尝试；失败则闪一下窗口）。
- ✅ 若实测通过，这就是零 Hook、真语音消息、全自动的方案。

## 四、建议

1. **先做 30 分钟可行性实验**（不写进主工程）：手动把麦克风切到 CABLE Output → 在微信文件传输助手里点麦克风录音 → 同时用任意播放器向 CABLE 播放一段变声 wav → 看手机上收到的语音消息是否正常有声。
   - 成功 → 按路线 A 开发完整功能；
   - 微信过滤虚拟声卡 → 回来我们再评估（届时可考虑老版微信 3.9 双开 + wcferry，或接受半自动）。
2. 实验通过后再动代码：新增 `wechat_voice.py` 模块 + `/api/wechat/send_voice` 端点 + 前端按钮。

> 备注：即使不做全自动，"TTS 生成 + 一键把微信窗口拉到该聊天并弹好录音"的半自动方案也可作为兜底。
