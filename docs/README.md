## 产品与研究

`product/` —— 产品界定、功能规格、竞品分析、路线图、用户研究计划；
`product/research/` —— 竞品痛点、自有产品走查、范围调整、麦克风选型、语音模型选型、差异化对标。
权威性有先后：**范围调整（`m1c`）与差异化对标（`m2`）优先于更早的《00_产品界定》**，冲突时以后者为准（文件里已写明）。

**`m1f_千问微调vsRVC-声音克隆裁决_2026-10-14.md`** —— 同素材正面对照「克隆自己的声音」谁更像：
**RVC 赢（跨 seed 区间不重叠），该 pass 的是「千问微调」这条克隆手段、不是千问引擎**；
并给出「自然度这一轴本次判不了」的尺子失效证据。原始分在 `大创申报-2026-10/千问微调vsRVC-裁决/`。

**`m1g_RVC翻唱混杂-调研_2026-10-14.md`** —— 翻唱「声音混杂、不纯粹」的社区调研 + 本机拆解：
**主因在素材、不在旋钮**。★ 源码里看着就是元凶的 `protect` 在本 fork 里是**死参数**
（`get_f0()` 先把无音高帧插值掉 ⇒ `pitchff` 恒为 1 ⇒ 0.33/0.5/0.0 三档输出**逐字节相同**）；
真因两条：① **变调没对齐 ⇒ 原唱音色泄漏**（保持原调时对原唱的 CAM++ 相似度 **0.2557**，
才是真正的"像两个人"）；② **训练素材的频谱倾斜被原样搬进输出**（4–8 kHz 掉 **18.5 dB**，
而拿自己的说话素材过同一模型只掉 2.5 dB）。**旋钮救不了"闷"，只能动素材。**

**`m1h_翻唱checkpoint扫描_2026-10-14.md`** —— 把 `m1g` 的待办「checkpoint e10–e40」排除掉：
**不换权重**（现役 e40 = `myvoice_ppt12_full` 保留）。★ e30 在两个 seed、**8/8 个细分频段
全部同号**地把能量从 **800–4000 Hz 搬到 200–400 Hz**（前者一致低 2.4–2.9 dB）⇒ 它是
"更浑厚"，**恰好加重"闷"**，不是"更亮"。另钉住一条指标误读：`centroid_hz` 是**谱质心
不是基频**（实测四档中位基频 123.1/123.5/124.0/123.8 Hz ⇒ 换权重不改音高）。
素材时长也不是杠杆（4≈8≈12min）。

**`m1i_分离模型对照_2026-10-14.md`** —— 排除「分离器漏伴奏」这个候选解释：
**不换 `htdemucs_ft`**（慢 1.5×、无可测收益；副歌段反而**更脏** 3/3 次、中位 −3.08 dB）。
★ 含一条方法论：**"两个东西差不多"必须先证尺子能分辨差异** —— 拿"整首歌 vs
分离人声"这种已知不同的一对做对照（差 **48.24 dB**），否则"没差异"无法证伪。
RoFormer/Kim_Vocal 本机没有，如实记为**未测**。

**`m1j_训练集预加重治闷_2026-10-14.md`** —— ★ **治「闷」的可落地杠杆**（不需要重录）：
把训练切片在 **2 kHz 以上按 +3 dB/倍频程预加重**后重训 ⇒ 产物 **4–8k 高 4.2–6.2 dB、
8–11k 高 6.0–7.6 dB、质心 +126~233 Hz**，而**总电平几乎不变**（是"高频被练进去了"，
不是变响）；**两组独立复现**（另一段时间 + 另一个 seed）。依据：RVC 前端瓶颈是 8 kHz，
而 4–8 kHz **就在瓶颈之内** ⇒ 抬它是"模型看得见"的改动。
⚠️ `t06`（+6 dB/oct）因 Windows 提交内存耗尽没跑完，"剂量越大越好吗"**未测**；
听感定稿仍需人耳（客观最优 ≠ 用户最满意）。

**`m1k_补录宽频素材A-B_2026-10-15.md`** —— 用户补录 4 条宽频录音（说话+唱歌，8–11k 比旧素材
高 ~40dB、零削波）后，"旧 12min 原样 + 新 2.8min"混训 vs 现役 t03 的两段 A/B：**宽频素材本身
成功，但原样混训没整体赢 t03** —— presence(4–8k) 与 CAM++"像你"两项 t03 两段都赢，只有"不沾
原唱"supp 两段都赢。现役先不换；最可能赢的下一版是「宽频新素材 **+** 预加重」（待验证）。
换不换最终以用户耳朵为准。
