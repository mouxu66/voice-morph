# docs 索引

本目录混着两类文档，读之前先确认手里这份属于哪一类：

- **现役（会随代码更新）** —— 与当前实现一致，看到不对就该改它。
- **历史快照（带日期，不再更新）** —— 某次审查/清理的过程记录。**里面的数字与结论只代表那一天**，
  别当成现状；但也别删：它们记录了"为什么当时这么改"。
