# 减负实测协议（大创减负层）

> **现役**。与 `tools/voice_load.py`（发声负荷测量）和 `tools/vfi_score.py`（量表计分）
> 的实现一致，看到不对就该改它们。
> 门禁：`m2_server/tests/test_voice_load.py` + `m2_server/tests/test_vfi_score.py`。
>
> **与 [`docs/嗓音保存评测协议.md`](嗓音保存评测协议.md) 的关系**：那边回答
> "复现的声音**像不像、录多久才够**"（RQ1–RQ3，质量边界）；这边回答
> "用它录课，**嗓子到底省多少**"（RQ-B，节省量）。两条合起来才是"减负"的完整论证：
> **质量是前提（那边），节省是结果（这边）** —— 缺任何一半，评审问"那减负本身
> 到底能不能成？"都接不住。

## 1. 三层证据结构（"减负"不是口号，是三层可辩护的证据）

| 层 | 内容 | 性质 | 状态 |
|---|---|---|---|
| **L1 发声时长节省**（最硬） | 同一节课，本人全程口播 vs 讲稿转旁白流程，量**发声总时长 / 连续发声时长 / 发声占空比**下降多少 | **客观、可复现、链路内可测** | 本协议 + `voice_load.py` 已落地，**待实测** |
| **L2 主观量表**（探索性） | VFI（嗓音疲劳指数）前后测 + VAS（0–100）每次录课前后自评 | 小样本、自评、**只看趋势不作硬结论** | `vfi_score.py` 已落地，**待实测** |
| **L3 文献因果链** | "发声时长/负荷下降 → 嗓音疲劳减轻"在职业嗓音文献被接受（教师嗓音干预 RCT，如 ReSt 应用 📚 立项后核验一手） | 引文，非本项目数据 | 申报书已按此口径写 |

机制就一条：**你自己不用开口了**。L1 直接测"不开口省了多少"；L2 探"主观感觉有没有跟着变"；
L3 补"L1 → 疲劳减轻"的文献后半段。三层都不越红线：**测的是发声时长与自评，不是疗效**。

## 2. 研究问题（减负层）

| 编号 | 问题 | 类型 |
|---|---|---|
| **RQ-B1（主）** | 同一节课，"讲稿转旁白"流程相对"本人全程口播"，**发声总时长、最长连续发声、发声占空比**下降多少？ | 定量、within-subject |
| **RQ-B2** | 走旁白流程一段时间后，VFI/VAS 自评是否出现下降趋势？ | 探索性（n 小，只看方向） |
| **RQ-B3** | B 侧产物的复现质量能否过自动门禁？ | **直接引用 RQ1 的结论**——质量前提不成立，节省量无意义 |

## 3. A/B 实验设计

### 3.1 两侧定义

| 侧 | 内容 | 本人开口部分 |
|---|---|---|
| **A（基线）** | 同一讲稿，**本人全程口播**录完整课（一条连续录音） | 全部 |
| **B（流程）** | 讲稿/备注 → 平台逐页合成旁白（复用本人音色，走既有讲稿录课链路） | **只有补录/改稿重录的开口录音**；写稿、审听、播放**不计**（没有口腔发声，也没有录音可测） |

★ B 侧本人发声**用录音文件计量**（把 B 流程里本人开口的每条录音都存下来喂给工具），
**不人工估时** —— 人估的"大概几分钟"既不可复现，也会往对自己有利的方向漂。

### 3.2 计量口径（★ 报结论时连同口径一起说）

- "发声" = **能量法**：ffmpeg `silencedetect` 自适应门限找静音（与嗓音保存协议 §4.3
  切档是**同一套实现**），发声段 = 全程 − 静音段。它量的是**发声活动时长**
  （speech activity time），**不是**严格生理 phonation time：呼吸声、桌面噪声可能计入，
  < 0.3s 的换气间隙算连续发声。职业嗓音文献的对应概念是发声时间剂量（time dose）
  与占空比（duty cycle，Titze vocal dose 框架）📚 —— 能量法是可接受的近似，别混同。
- **电平必须达标**（录音协议 §4.1：同麦、峰值 ≤ −3 dBFS）：低电平录音会被门限整段
  吞成"没发声" → 占空比假低 → 节省率假高。每次测量**先看 JSON 里的 `peak_dbfs`**。
- A/B 两侧**用同一组参数**测（同 `--min-silence`、同门限策略），参数随 JSON 落盘。

### 3.3 控制与顺序

- 同一人 / 同一麦 / 同一房间 / **同一讲稿**（内容变了就不是"同一节课"）。
- 顺序效应：讲同一遍课第二遍更熟。**AB / BA 交替平衡**（一半被试先 A 后 B，
  一半相反），两轮至少隔一天。
- B 流程里本人开口的录音命名即脱敏（`s01_retake_01.wav`），从命名开始不带真名。

### 3.4 规模

- **Pilot：3 人**（与《真人小样本试跑-执行卡》同批被试可合并：录完音色顺手做 A/B）。
- **主实验：12 人**（与 §2.4 主实验同批师范生），AB/BA 交叉 + VFI 前后测。
- 写进申报书时必须标注：n、健康说话人、能量法口径、**不外推总体**。

## 4. 指标定义

| 指标 | 定义 | 来源字段 |
|---|---|---|
| 发声总时长 | 发声段时长之和 | `phonation_s` |
| 发声占空比 | `phonation_s / total_s` | `duty_cycle` |
| 最长连续发声 | 最长发声段（< min_silence 的间隙算连续） | `longest_continuous_s` |
| **发声时长节省率** | `(A.phonation − ΣB.phonation) / A.phonation` | `saving.saving_rate` |

> A 侧发声为 0 时节省率返回 `null`（未定义），工具**绝不**编 0% 或 100%。

## 5. 测量工具用法

```bash
# ① 单文件测量（看占空比/连续段长什么样）
.venv/Scripts/python.exe tools/voice_load.py measure lesson_self.wav --json out.json

# ② A/B 对比（B 侧所有开口录音都给上）+ 合成旁白只记时长
.venv/Scripts/python.exe tools/voice_load.py compare \
    --a lesson_self.wav --b s01_retake_01.wav s01_retake_02.wav \
    --synth narration.wav --json compare_s01.json

# ③ 量表计分（回收 CSV → 因子分 + 汇总；非法值上报不夹紧）
.venv/Scripts/python.exe tools/vfi_score.py --template          # 先拿表头模板
.venv/Scripts/python.exe tools/vfi_score.py --in 甲.csv 乙.csv --out vfi_scores.csv
```

**每次实验后**：`--json` 落盘文件与录音一起归档（参数在里面，换参数 = 换口径）。

## 6. 主观量表（L2，探索性）

- **VFI**：19 条、0（从不）–4（总是），三因子（11 用嗓后疲劳与嗓音恶化 /
  5 躯体不适 / 3 休息后改善）📚 Nanjundeswaran et al., 2015, *Journal of Voice*，
  立项后核验一手；是否存在经信效度检验的中文版 ❓ 未核验。**题目原文不入库**
  （本仓开源 + 量表条目有版权）：研究者从一手文献誊录进自己的问卷，回收按
  `v01..v19` 填 CSV，本工具只做计分。**未核验前只报因子分，不做分档/诊断。**
- **VAS**：0–100 单条自评，每次录课前、后各一次（`vas_pre` / `vas_post`）。
- **知情同意**：按嗓音保存评测协议 §9 执行（用途、只留本机、可随时退出、留签字件）。
- 报告口径：**探索性指标**，只描述趋势方向，不作显著性硬结论。

## 7. 文献因果链（L3）

- 申报书的写法：**"减负的技术前提是声音像你且像真人，这个前提的质量边界正是
  本研究要回答的"**（§2.1 已写）—— 那是**前提**；本协议补**结果**：机制有文献
  （L3）、手段有平台、节省量有实测方案（L1）。
- 前半段（发声时长下降）自己测；后半段（时长下降 → 疲劳减轻）**引职业嗓音文献**，
  不自己声称。ReSt 等教师嗓音干预 RCT 属这一类证据 📚 立项后核验一手再引。

## 8. 诚实边界与红线

1. **测的是发声时长与自评，不是治疗效果**；全文无"已减轻嗓音疾病"类表述。
2. B 侧本人开口可能为 0 → 如实写"该课本人口腔发声 X 分钟（B）"，**不写成
   "零负担"**：写稿、审听的时间成本是真实存在的，本协议只对**发声**负荷负责。
3. 能量法口径的近似性（§3.2）随结论一起报；低电平素材的测量结果不采信。
4. 申报书口径只写"定位/拟应用 + 实测方案"，拿到 L1 数据前**从不说"已减轻"**。
5. 结论不外推：n、人群、单机单卡、中文 —— 同嗓音保存协议 §9 的边界条款。

## 9. 申报书粘贴模板（拿到数据后照填，别手改口径）

> **减负实测（RQ-B，within-subject，n=3 pilot / n=12）**：同一讲稿下，本人全程口播
> 与讲稿转旁白两种流程的发声负荷对比显示：发声总时长由 X 分钟降至 Y 分钟
> （节省 Z%），最长连续发声由 X' 降至 Y'；主观 VFI/VAS 前后测（探索性）趋势
> 同向/未见一致变化。本层测量对象为**发声时长与自评**，不构成任何疗效结论；
> "发声负荷下降 → 嗓音疲劳减轻"引自职业嗓音文献（立项后核验一手）。
