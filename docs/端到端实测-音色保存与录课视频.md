# 端到端实测：上传音色 → 保存 → 用它录课出视频（2026-10-10）

> 测试方式：Windows 桌面自动化驱动真实 GUI（Chrome 加载 `localhost:5173`，与 Electron 同一套前端/后端），
> 全程模拟"老师"操作：上传一段录音 → 音色工坊切片/质检/采纳 → 存成音色 → 录课页上传 PPT → 逐页合成 → 导出成片。
> **目的**：回答两个问题——①音色存不存得住？②用保存的音色录视频，会不会出问题？

## 结论先行

| 问题 | 答案 |
|---|---|
| 音色保存得住吗 | ✅ **存得住**。后端 `/api/voices` 出现 `teacher_voice`，`media/voicebank/teacher_voice/` 落盘，重启后端后仍在 |
| 保存的音色能录视频吗 | ✅ **能，全链路一次跑通**。3 页 PPT → 3 条旁白（58.8s）→ 1920×1080 mp4 成片 59.5s，零失败 |
| 像不像本人 | ⚠️ 首测 SECS 0.806 → **✅ 修复后 0.9905**（2026-10-10 晚：成片"电音"实为 float32→pydub 位级错读 bug，与参考音质量无关，见下文平反记录；同人上限 0.9928） |

## 链路实录（每步实际发生的事）

1. **上传素材**：120s 本人录音（lesson_A.wav 截段）封装成 mp640×360 黑屏视频（音色工坊**只收视频格式**，见问题③）。
   放进 `media/raw_videos/` 后应用即刻识别（素材列表 2 → 3）。
2. **切片流水线**：点「运行流水线」→ 26 条切片（A/B 级），约 2 分钟（首次含去 BGM 模型下载）。
3. **质检采纳**：按「A」筛选 → 「批量采纳」两屏 → 26 段 / 117.7s。
   ⚠️ 目标 30s、超额采纳 117.7s **UI 不拦截**（问题⑤）。
4. **创建音色**：「进入音色库」带勾选素材过去 → 填 ID `teacher_voice` → 「创建参考音色」→ 后端确认创建成功。
   ⚠️ **「我的音色」页刷新后列表不显示它**（只有袋鼠骑士 v2），但数据真实存在（问题②）。
5. **录课合成**：录课页音色下拉 **直接出现「teacher_voice（自训）」并选中** → 上传 3 页测试 PPT
   （备注自动带出为讲稿）→ 「逐页合成」→ 3/3 成功（P1 23.7s / P2 19.4s / P3 15.7s），每页独立音轨 + 波形试听。
6. **导出成片**：「课件画面 + 旁白 → 视频」展开 → 30fps / 页间停顿 350ms → 「导出成片」→
   **59.5s，1920×1080 H.264 + AAC**，`outputs/course_1791599316778/course.mp4`（1.8MB）。UI 徽章同步显示「59.5s · 3 页画面」。

## 音色相似度客观验证（CAM++ 声纹，SECS 余弦）

| 对照组 | SECS |
|---|---|
| 本人两段不同录音（**同人上限**） | **0.9928** |
| pilot：手工挑 10s 干净参考音直接合成（前一轮实验） | 0.9888 |
| **本轮：音色库端到端（切片→采纳→自动参考音→成片）** | **0.8060** |

**0.806 的解读**（⚠️ 已被推翻，见下）：仍显著高于跨人区间（通常 <0.7），听感"像本人"；但相对手工参考音有明显损耗。
归因（待逐项验证）：音色库参考音由流水线从 26 段切片自动构建，切片含 16kHz 重采样与不同信噪比段；
pilot 那条是原始 24kHz 干净段直通 TTS。**改进方向**：采纳阶段用更严的质量阈值（只要 A 级、拉长最短时长），
或对构建出的 `reference.wav` 跑一次 `clone_eval` 再确认。

### 平反记录（2026-10-10 晚）：0.806 的元凶是位级错读 bug，不是参考音质量

用户听成片反馈"全程电音、刺耳"。逐页 wav `astats` 检查实锤：三页 peak **一模一样**
（-4.997549 dB）、RMS -6.4 dB、Flat factor ≈9.8 —— float32 PCM 字节被
`AudioSegment(sample_width=4)` 按 int32 位级重解释，波形整体顶平成数字噪音
（工程档案 §8.70）。修复（`course_api._pcm_to_segment`，经 int16 落地）后同一音色、
同一课件重出：

| 对照组 | SECS |
|---|---|
| **修复后：同音色（teacher_voice）+ 同课件重新合成出片** | **0.9905** |
| 修复前（本轮首测，电音版） | 0.8069 |
| pilot 手工参考音 | 0.9888 |
| 同人上限 | 0.9928 |

修复后反超手工链路 —— **teacher_voice 自动参考音质量本来就够**，首测的"损耗"
几乎全部来自电音失真。新成片 `outputs/course_1791606782378/course.mp4`（59.8s，
1920×1080，音轨 Flat 0 / RMS -30 dB），三页 peak -8.4/-9.8/-11.7 自然分布、Peak count 3。

## 发现的问题（按影响排序）

| # | 问题 | 影响 | 建议 |
|---|---|---|---|
| ① | 音色工坊上传**只收视频格式**（mp4/mkv/mov/flv/webm/avi），纯 wav/mp3 不收 | 老师最自然的操作是"传一段录音"，现在必须先封装成视频 | accept 列表加音频格式，或上传 wav 时自动转封装 |
| ② | **「我的音色」页不显示 clone 类音色**（后端有、录课页下拉也有，唯独列表页不显示） | 用户会以为"没保存上"而重复创建 | 列表查询过滤条件补 `kind=clone` |
| ③ | ~~端到端音色相似度损耗（0.806 vs 手工 0.9888）~~ **✅ 已解决（2026-10-10 晚）**：真凶是 float32→pydub 位级错读 bug（§8.70），修复后 0.9905 反超手工链路；参考音质量本就够 | ~~成片"像本人"打折~~ 电音失真 | ~~采纳阈值收紧~~ 已修 `course_api._pcm_to_segment`；"采纳阈值收紧/SECS 门禁"降级为锦上添花 |
| ④ | 质检台**卡片级按钮**（单个「采纳」、卡片「自动优选」）桌面自动化点击无响应，「批量采纳」正常 | 本次未定论是自动化点击层问题还是前端事件绑定问题，需人工复核 | 人工点一次卡片「自动优选」验证；若真失效则是 P1 bug |
| ⑤ | 超额采纳不拦截（目标 30s，采纳 117.7s 直接过） | 参考音过长可能引入更多噪声段（与问题③相关） | 超额 >2× 时提示确认 |
| ⑥ | 「今天怎么用？」对话框每次刷新都弹（未选套餐时） | 自动化/回测反复手工关闭 | 记住"直接进入"的选择 |

## 测试环境备注

- Electron 壳在本机自动化环境下无法启动（沙箱限制 GUI 会话），改用 Chrome + `localhost:5173`——同一套 React 前端与 FastAPI 后端，测试有效性等价；桌面壳表现（托盘/桌宠/IPC）不在本轮范围。
- 打包版 `release2` 是 9/23 旧壳，**不含讲稿录课页**，测试必须跑源码（`npm run dev` + 当前 `web/dist`）。
- 能力开关「训练变声（音色工坊）」「音色挖掘」默认关闭，需在能力管理打开并**重启后端**生效。
- 复现命令与全部产物：素材 `media/raw_videos/teacher_voice_upload.mp4`；音色 `media/voicebank/teacher_voice/`；
  成片 `outputs/course_1791599316778/course.mp4`；逐页音轨同目录 `page_001..003.wav`。
