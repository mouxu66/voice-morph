# A2 落地说明 · 安装后自动生成试听

> 对应《功能完善建议-2026-09-05》A 档第 2 条。

## 解决什么问题

实测 chaye741 / hudddd 等市场仓库**都没有演示音频**（只有 weights/indices），市场页「试听」长期不可用，用户必须装完才知道像不像。现在：**安装收尾自动合成一句固定中文试听**，市场卡片与音色库共用播放器，把「装了才知道翻车」变成「装了先听再留」。

## 链路

安装完成（`market_install.py` 收尾）→ `market_preview.try_auto_preview(voice_id)`（fire-and-forget，失败不阻塞安装）

后台线程里走完整链路：

```
固定一句中文
  └─ 用本机任一 voicebank 参考音色 → Qwen3-TTS 合成源句（缓存 outputs/market/_preview_src.wav，只做一次）
       └─ 走 RVC 离线推理（offline_vc_infer.py 子进程，与离线变声同一条链路）
            └─ outputs/market/<id>_preview.wav（市场卡片 / 音色库共用播放）
```

**源句缓存**：`_preview_src.wav` 首次生成后复用，不会每个音色都烧一次 TTS；无任何 voicebank 时报可读原因（failed），提示先去建一个音色。

## 状态模型

每个音色一个 sidecar（`outputs/market/<id>_preview.json`）：

| 状态 | 含义 | 前端表现 |
|---|---|---|
| `ready` | 试听已生成（wav 存在，sidecar 可脏） | 播放器 |
| `generating` | 生成中 | 转圈 +「试听生成中…」 |
| `failed` | 生成失败，error 带原因 | 「重新生成试听」按钮（hover 显示原因） |
| `skipped` | GPU 被实时/级联/离线变声占用（不静默排队） | 同上，可稍后重试 |
| `missing` | 从未生成 | 有安装就触发，否则无 |

## 验证

## 已知边界

- GPU 忙 → `skipped` 而非排队：避免长任务堆积，前端可手动点「重新生成试听」。
- 试听依赖 RVC 集成包 `.venv` 存在；缺失时报可读 failed，不阻塞安装本身。
- TTS 首启冷启动可能较慢（worker 加载 4GB 模型），前端轮询最长约 3 分钟。
