### 标签怎么做到近乎零噪声

Whisper 转真人普通话仍有 **15–20% 错字**（实测：`顾客人群`→录课人群、`用丧`→用嗓、
`生意银行`→声音银行、`零端客龙`→云端克隆）。8 月就是死在这里。

本次有本人讲稿 `docs/大创申报-2026-10/答辩讲稿-19页.md`（3,343 字），做法：

1. Whisper 转写全片 → 3,218 字 / 232 段；
2. 用 `difflib.SequenceMatcher` 把 ASR 流与讲稿流做长程对齐，建"ASR 字符 → 讲稿字符"单调映射
   （`ppt12_verify_clips.py`），讲稿覆盖 **99.7%**；
3. **文本一律取讲稿原文，只取确实匹配上的连续片段**；ASR 只用来定时间边界；
4. 切点吸附到能量最低帧（不在字中间切）；字速门禁 2.2–9.0 字/秒剔除异常段。

结果：**命中率 0.94**（即约 6% 处他即兴改写，非逐字念稿 —— 这条如实记录，
不是"零噪声"，是"比 Whisper 好 3 倍"）。

> ⚠️ 发现：录音是从**更早版本**讲稿录的。他念的是"后端 37000 多行 / 2847 个测试"，
> 而讲稿文档现写"39,627 行 / 3,113 个"（见 `P13改造-已完成.md` 记录旧值 37,872/2,847）
> → 讲稿在录音后有修订。**这不影响训练**（标签取的是讲稿对应段落），但说明
> "讲稿 = 逐字稿"这个假设要留余地。

## 四、根因：训练/推理 prefill 错位 1 个 token（已定位到行）

用 forward hook 同时捕获两条路径的 prefill 并逐行比对：

```
训练侧 build_prefill_embeds : shape=(1, 20, 2048)
推理侧 generate() 首帧      : shape=(1, 21, 2048)   ← 多 1 行
逐行平均绝对差：行 0-6 = 0.00000（完全一致）
                行 7-19 起偏移 0.017~0.045
余弦相似度 = 0.9146                                 ← 不一致
```

**精确定位**（读 `modeling_qwen3_tts.py`）：

| 位置 | 代码 | 下标 |
|---|---|---|
| `generate()` 第 2240 行 | `input_id[:, 4:-5]` | 从 **4** 开始 |
| `sft_12hz_qlora_aligned.py` 第 120 行 | `input_id[:, 3:-5]` | 从 **3** 开始 |

**起始下标差 1** → 训练时文本段整体比推理时早一个 token，两者差一行。
LoRA 在这个偏移分布上学到的修正，套回推理分布即吐噪声。

> 这与 8 月记录的坑**同类不同因**：8 月是"手写拼接 vs 官方 prefill"完全错位
> （loss 卡在随机线 8.03 不降）；本次 loss 降得很好（3.41），说明
> `build_prefill_embeds` 已经**大体**复刻成功，只剩这 1 个 token 的偏移。

## 五、结论与建议

1. **A 臂（现役零样本克隆）完全可用**：CAM++ 0.753、ASR 0.93、各项客观指标正常。
   就"用我的声音念课件"这个用途，**零样本路线当前是唯一可交付的路线**。

2. **B 臂（12 分钟 LoRA 微调）训练成功但推理不可用**，卡在 `build_prefill_embeds`
   与 `generate()` 的 1-token 偏移。**这是工程问题，不是数据问题、不是"12 分钟不够"
   ——数据比 8 月好 2.7 倍、loss 比 8 月更低。**

3. **下一步（按性价比排序）**：
   - ① 把 `sft_12hz_qlora_aligned.py:120` 的 `input_id[:, 3:-5]` 改成 `input_id[:, 4:-5]`，
     与 `generate()` 对齐，重训 + 重测（成本约 0.5–1 天）；
   - ② 若修好，再跑本报告的 A/B 评测复现；
   - ③ 修不好的话，**零样本路线选型就是正确结论**——用数据回答导师那句"深究微调"。

4. **对申报书的价值（无论走哪条）**：本报告本身就是"零样本 vs 微调"的同素材对照数据。
   赢了是技术改进；打平/失败就用数据证明"12 分钟量级下微调无增益，零样本选型正确"。
   **两种结果都是正资产**。

### 环境坑（本次踩到）

- **repo 副本遮蔽已安装包**：`sft_12hz_qlora_aligned.py` 原先把 `Qwen3-TTS/` 插到
  `sys.path[0]`，其中 `qwen_tts/` 用旧版 `@check_model_inputs()` 写法，与
  transformers 5.16.1 不兼容（`TypeError: missing 1 required positional argument`）。
  已改为只插 `finetuning/`（为 `dataset.py`），需要时用 `VM_QWEN_TTS_ROOT` 显式覆盖。
- **`generate()` 的 `input_ids` 要 list 不是 2D tensor**：签名是
  `Optional[list[torch.Tensor]]`，内部 `enumerate(input_ids)` 逐条处理；
  传 2D tensor 会被按行迭代成 1D → `input_id[:, :3]` 报
  `IndexError: too many indices for tensor of dimension 1`。
- **CAM++ 对超长音频返回 None**：766s 整条输入失败，需切 20s 分段平均
  （`ab_evaluate.py::cam_emb` 已实现）。
- **Whisper 常吐繁体**：算字符重合度前必须 `zhconv.convert(..., 'zh-cn')`，
  否则简繁差异会把重合度全算错（本次一度把 0.79 算成 0.50）。
- **8 月验收口径（只看 zcr + unique + 时长）不足以发现内容崩坏**：本次控制实验中，
  崩坏样本的 zcr/unique/时长恰好落在 8 月"正常"区间内，但 ASR 回译是
  「我全都他所想」「他死下了他死下了」。**必须加 ASR 可懂度和 peak/削波两项。**
