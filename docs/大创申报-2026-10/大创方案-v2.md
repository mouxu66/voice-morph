## 1. 题目与定位

**主推**：面向职业用嗓人群的本地声音保存与少样本复现质量研究

**备选 A**：本地离线声音保存系统的构建与复现质量边界评测
**备选 B**：面向师范生职业嗓音风险的本地声音保存与复现研究

**定位口径**（沿用旧简报铁律）：研究训练 + 系统集成创新 + 场景落地。
**不写**"产品 / 创业"；**禁用**"首次 / 领先 / 唯一"。

## 2. 为什么是这个题（四层论证，每层都有出处）

### 2.1 有意义 —— 职业用嗓人群是真实的高危群体，而且就在本校

- 📚 国内流行病学数据：普通人群嗓音疾病发病率约 **6%**，中小学、幼儿园教师患病率高达 **33.81%**（来源：搜狐 2026-09-09 转载，**二手，需核一手**）。
- 📚 国际上存在"教师嗓音疾病全球患病率"的系统综述与 meta 分析（yfsci / ScienceDirect），以及"职业用嗓与嗓音疾病关联"的 meta 分析（Cutiva 等）→ **该人群的流行病学基础是受学术界承认的**。
- 📚 教师职业病明确含慢性咽炎、声带小结、声带息肉（光明网教育频道 2026-09-09）。
- ★ **师范生 = 未来的教师**。被试、目标人群、学校身份三者重合 → 校地契合度最高，且**不需要碰任何患者**。

> 叙事链：职业用嗓 → 声带可能受损 → 提前保存声音 → 但现有方案都有代价 → 本项目回答"代价有多大"。

### 2.2 有对照对象 —— 正好是申报书铁律要求的

来自 ALS 官方指南（`youralsguide.com/voice-banking.html`，ALS Association 生态，📚）：

| 方案 | 录制门槛 | 缺口 |
|---|---|---|
| 传统声音银行（Acapela / SpeakUnique / The Voice Keeper / ModelTalker） | **50–200 句** | 录制负担重，合成音偏机械 |
| Apple Personal Voice | 免费、端侧 | **仅限 iPhone/iPad/Mac**，不覆盖 Windows |
| 云端 AI 克隆（ElevenLabs 等） | **1 分钟**得 instant clone，**10+ 分钟**才接近本人 | ★ **必须联网**——原文："在医院、护理机构、飞机上无法使用"；约 $1200/年 |
| **本项目** | **秒级参考音** | **待回答：质量代价有多大？** |

★ **第 3 条是本项目真正的差异化支点**，不是"Windows 没人做"：
**离线可用性**对行动受限人群是刚需，且这句话有权威出处可引。

### 2.3 可行 —— 不需要患者，全部本机

- 实验对象改为**师范生健康说话人**（自录），动机仍是"嗓音保存"，但**实验不碰患者** → 无伦理审查障碍、无招募障碍。
- 算力：RTX 5060 8GB 已在手，RVC 实时 p50 ≈ 50ms ✅，Qwen3-TTS 小样本克隆已跑通 ✅。
- 工具链**已存在**，见 §4。

### 2.4 契合 —— 用的是项目真正的壁垒，不是丢掉它们

项目的护城河有两样，这个题**两样都吃满**：
1. **本地离线 + 跨应用注入**（VB-CABLE → 微信/游戏已验证 ✅）
2. **客观质量评价栈**（`voice_metrics.py` + `voice_qc.py` + `ab_api.py` 盲听页 + `quality_verdict.py`）

而"做一个声音银行 App"会把这两样都绕开（只剩离线 TTS + 录音 UI）。

## 3. 研究设计

### 3.1 研究问题

- **RQ1（主）**：参考音时长从 3s 增到 60s，复现质量如何变化？**收益在何处饱和？**
- **RQ2**：不同文本条件下（同文 / 跨文 / 跨情感 / 长句），同一参考音的复现质量差异有多大？
- **RQ3**：客观指标与人工主观评分（MOS / ABX）的相关性如何？**能否用客观指标替代人工听测做自动门禁？**

> RQ3 是"研究训练"的核心，也是产品层"自动质量门禁"的直接输入。

### 3.2 实验矩阵

| 维度 | 取值 |
|---|---|
| 说话人 | **N = 12**（师范生，男女各半），安静房间 + 统一麦 |
| 自变量：参考音时长 | **3s / 10s / 30s / 60s**（同一批录音的不同截取，控制音质一致） |
| 条件：复现文本 | ① 同文 ② 跨文（日常句） ③ 跨情感（高兴/生气/悲伤） ④ 长句（>30 字） |
| 对照 | 传统 VB 50–200 句、云端 1min 克隆（**文献口径对照**，不做实验） |
| 听测被试 | **N = 24**（同学），随机抽样、盲听、不显示条件 |

样本规模：12 × 4 × 4 = **192 个合成样本**，可控。

> ★ **档位口径的唯一真相源**：`m2_server/voicepreserve.py:REF_DURATIONS`
> ＝ `tools/voicebank_eval.py:DURATION_LADDER` ＝ `docs/嗓音保存评测协议.md` §3.1，
> 均为 **3 / 10 / 30 / 60 四档**（2026-10-03 拍板统一，此前本文件误写为含 5min 的五档）。
> 不设 5min 档有两个理由：① 录音脚本 `RECORD_SCRIPT` 仅 30 句
> （`script_capacity_s()` ≈ 91s），而档位的定义是「按顺序念、取前 N 秒」
> —— **物理上录不出超过脚本容量的档**；② 传统声音银行 50–200 句那一档是
> **文献口径对照**，不需要我们在实验里真录一档 5min 去凑。
> **改档位必须三处同改**（代码 / 评测协议 / 本文件）。

### 3.3 测量

**客观（全自动，工具已有）**
| 指标 | 工具 | 口径 |
|---|---|---|
| 相似度 | CAM++ 声纹余弦 | 现役判据 ≥0.95（`voice_qc.py`） |
| 自然度 | HNR（浊音帧中位数） | `voice_metrics.py` |
| 发声健康 | H1-H2 + 谱倾斜（取更危险档） | `voice_metrics.py` |
| 稳定性 | jitter_local / shimmer_local | `voice_metrics.py` |
| 可懂度（新增） | ASR 回译 WER | 复用已有 ASR，**零被试成本** |

**主观（人工听测）**
- MOS 自然度 5 分制 + ABX 相似度（与真实录音二选一）
- 用**已有** `ab_api.py` 盲听页，随机化 + 不显示条件

### 3.4 分析

1. **主效应**：参考音时长 → 各指标（重复测量 ANOVA / 混合效应模型）
2. **饱和点**：找到"再增加时长，收益 < 阈值"的档位 → **回答"最少要录多久"**
3. **相关性**：客观指标 vs MOS/ABX（Spearman / PLCC / SRCC）
4. **门禁**：用相关性最高的指标组合定阈值，验证"自动门禁 vs 人工判断"的一致率

### 3.5 诚实边界（写进申报书，不要藏）

- 以**健康说话人**模拟"嗓音保存前的录制条件"，**不是患者数据**。
- 样本量小（12 人 / 24 听测者）、单机单卡、单语言（中文）。
- 不做任何**疗效**声称，只做"保存与复现的质量评价"。
