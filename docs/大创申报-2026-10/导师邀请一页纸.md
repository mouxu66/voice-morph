## 【致老师】可直接复制

尊敬的 `【导师姓名】` 老师：

您好！我是 `【学院】` 的 `【牟旭】`，想请您指导我们申报 **2026 校级大学生创新创业训练项目（创新训练类）**。

**一句话**：我们做**面向录课人群用嗓减负的「本地声音系统」**——用你自己的声音替你录课
（讲稿逐页转旁白 / 提前保存音色续录），并系统评测它在**不同录音时长下的复现质量边界**——
所有声音数据处理**全程离线、不出本机**。

**为什么觉得这事值得做**：

1. **它是真问题，且现有方案都有硬缺口。** 录课、网课是教师与师范生的日常——一节课连续讲几十分钟、
   反复重录，**用嗓负担真实存在**（教师嗓音疾病患病率约 33.81%，普通人群约 6%）。想"用自己的声音替
   自己录课"，前提是把声音复现好——但**传统的"声音银行"要录 50–200 句**，门槛极高；
   主流的 AI 克隆**必须联网**——`[ALS 协会生态的官方指南明确写着：AI 克隆在医院、护理机构、
   飞机上无法使用]`（有出处可引）。而"**离线可用 + 秒级小样本**"这一格，目前**没有系统性研究**。

2. **我们有很硬的前期基础，不是从零起步。** 团队已独立完成一个可运行的桌面端实时语音系统：
   **后端 37,872 行 Python、前端 40,169 行 TS/TSX、2,847 个测试、27 个能力插件、CI 门禁、
   代码已在 GitHub 开源**。克隆引擎（Qwen3-TTS 秒级小样本）与实时链路（消费级 GPU 上
   端到端 p50 ≈ 300 ms，含分块缓冲 250 ms + 单块推理 30 ms + 驱动缓冲 ~20 ms）**都已经跑通**。

3. **它的研究问题是真的"研究"**，而不只是"做个软件"：
   - **RQ1**：参考音时长从 3s 到 60s，复现质量如何变化？收益在哪里饱和？
   - **RQ2**：不同文本条件（同文/跨文/跨情感/长句）下质量差异有多大？
   - **RQ3**：客观指标与人工主观评分（MOS/ABX）的相关性如何？能否用客观指标做自动门禁？
   评测引擎（1559 行 + 99 个测试）与正式评测协议**已经写好**。

4. **贴合我们师范院校的身份。** 核心应用场景就是**录课减负**（微课、网课、课堂音频），
   研究对象是**职业用嗓人群**（教师、师范生、播音等）——与我校培养方向直接相关。

**我们需要的指导**：研究设计的把关（尤其 RQ3 的主观听测方法与统计）、
以及项目流程上的指导与签字。

**我们能保证的**：不占用您过多精力——技术实现我们自己扛，
把复盘与决策点整理成**一页纸**定期同步；经费按学校规定如实申报使用。

随附：项目进度 PPT（19 页，PDF）。若您方便，我想约 **15 分钟**当面汇报。

## 【给自己看】如果老师问这几个问题

**Q：这不就是个软件吗，研究在哪？**
A：软件是**载体**。研究问题是"**参考音时长 → 复现质量的收益边界**"，
以及"**客观指标能否替代人工听测**"——这两个问题现有文献**没有系统答案**。
软件已经做完了（所以可行性 20 分稳），我们要做的是**用它把这两个问题回答掉**。

**Q：数据从哪来？**
A：**12 名师范生被试**（知情同意），同一人/同一麦/同一房间一次录制，
按前缀切 3/10/30/60s 四档——**控制变量**是关键，所以不能用现成素材替代。
（实际只需每人录约 65 秒，不占太多时间。）

**Q：会不会有伦理/滥用风险？**
A：这正是我们第三个创新点 **consent-by-design**：克隆前必须显式同意、
档案 id 正则防越权、只追加审计日志、**声音全程不出本机**——
把伦理做成**设计约束**而不是口号。此外**溯源水印已经落地**：
生成的音频可嵌入隐形标识，**转码后仍能检出并给出概率**（口径只说"可检出、可溯源"，
不说"防伪"）。

**Q：你一个人做得完吗？**
A：团队 4 人：我负责系统实现与评测引擎（已就绪）；
其余三人分别负责**被试招募与录音实施 / 主观听测组织 / 文献综述与对比实验**——
每人都有**可交付物**。且技术侧已经跑通，立项后是"**优化—验证—结题**"，不是"从零搭"。
