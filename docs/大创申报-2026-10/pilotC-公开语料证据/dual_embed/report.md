# 双空间声纹最小实验 · pilotC

- 生成时间：2026-10-11 10:39:30　|　样本：48 同人配对 + 96 异人配对（同档、别的说话人）

## 3 怎么读

- **AUC** = P(同人分 > 异人分)：0.5 等于扔硬币，1.0 是完全分开。**EER** 越低越好，**d′** 越大越分得开。
- **≥0.98 占比**看天花板占用：同人分都挤在 0.98 以上时，阈值型门禁几乎没有分辨空间（全过或全挂）。
- 分离度看“能不能区分你是不是我”；天花板占用看“在同人区间里还能不能分辨好坏”——自动门禁需要的是后者。
