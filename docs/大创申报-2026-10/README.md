## 五、口径红线（答辩时别踩）

1. **不宣称"首次 / 领先 / 唯一"** —— 创新点必须给"对照对象 + 数据"。
2. **定位口径 = 研究训练 + 系统集成创新 + 场景落地**，**不写"产品 / 创业"**（这是创新类）。
3. **不宣称医疗效果** —— 本项目是"录课用嗓减负的本地声音复现与质量边界研究"（2026-10-09 定位更新），不是治疗。
4. **"减负"是应用定位，不是效果声称** —— 可以说"以录课用嗓减负为应用定位"；**不能说"已减轻/已解决录课负担"**，成效口径永远是"减负的技术前提（复现质量、录多久才够）正是本研究要回答的问题"。
5. **"已有基础"是前期基础，不是项目本身** —— 单独成节（§4.1），避免评审误判为"已完成"。
6. **科学诚信**：RQ1 四档（3/10/30/60 秒）定义为**同一段录音的前缀截取**，控制变量 = 同一人/同一麦/同一房间；**不能拿下载素材冒充**。录制约 65 秒/人即可覆盖最高档。
