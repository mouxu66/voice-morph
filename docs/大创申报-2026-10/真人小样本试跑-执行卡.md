> **目的**：把申报书 §4.2「现有结论」从**链路验证**变成**真人数据**。

## 0.5 路线 B：找不到真人时，用**公开许可语料**顶上（✅ 2026-10-08 已做完）

`emb_sim` 0.9815→0.9843→**0.9854**→0.9854，饱和档 30s）+ `media/vocals/public_pilot/SOURCES.json`。

```bash
# 许可白名单是**机器门禁**：manifest 写 CC-BY-NC-ND 直接拒绍执行，一条都不下
.venv/Scripts/python.exe tools/voicebank_fetch_public.py \
```

## 1. 三个半天怎么排

| 天 | 谁 | 做什么 | 产出 |
|---|---|---|---|
| **D1（半天）** | 你 + 3 名同学 | 每人 15 分钟：知情同意 → 录 1 段 ≥65s 连续参考音 → 四个条件各念一遍 | `refs/` 源文件（每人 1 条）+ `truth/` 12 条 |
| **D2（半天，多半是等待）** | 你（一个人） | `split` 切四档 → `synth` 合成 48 格 → `measure` | `results.csv` + `provenance.json` |
| **D3（半天）** | 你 + 5–8 名听者 | 发 `sheet.csv` → 收评分表 → `merge-listen` → `analyze` | `subjective.csv` + `report.md` |

> 听测**可以并行**：D2 合成完就能发评分表，不必等测量跑完。
> 听者用同一副耳机、音量固定、环境安静（协议 §6.2）。

## 2. D1 · 录音现场执行卡（打印出来照着念）

### 2.1 录之前（每个说话人都一样）

- 房间：安静、关窗、关空调/风扇；**别在走廊和教室**。
- 麦克风：全程**同一支**，嘴到麦 15–20cm，偏轴约 30°。
- 增益：固定，**峰值不超过 −3 dBFS**（削波直接毁掉 HNR 与 jitter）。
- 格式：WAV 44.1k/48k 单声道。
- **知情同意**：先跑 [`docs/嗓音保存评测协议.md`](../嗓音保存评测协议.md) §9 那几条 ——
  说明用途、保存位置（只在本机）、销毁方式、随时可退出，并留存一份签字的同意书。

### 2.2 打印录音脚本

```bash
.venv/Scripts/python.exe tools/voicebank_eval.py corpus
```

脚本约 30 句 / 容量 ~91s。**要的是"一次性连续录完"**，不是逐句录。

### 2.3 ① 参考录音（一次录满 ≥65s，最关键的一条）

> 让同学按脚本**从第一句开始连着念**，中间不要停、不要重来，录够 **65 秒以上**。

★ 为什么必须一次录完：四个时长档是**同一段录音的前缀截取**。
分四次录 = 把"这次录得好不好"混进"时长"这个自变量里，RQ1 直接失效。

**当场质检**（语速 > 6 字/秒 或 有爆音/电流声 就重录）：

```bash
.venv/Scripts/python.exe tools/voice_qc.py --dataset <刚录的目录>
.venv/Scripts/python.exe tools/check_recording.py     # 有的话一并跑
```

### 2.4 ② 四类复现文本各念一遍（这是 ABX 的对照，必须有）

`corpus` 打印的 `repro_texts` 里，`same / cross / emotion / long` **各挑第一条**念一遍，
每次都**从头完整念**，每条单独存一个文件。

### 2.5 ③ 文件落位（别手工拷错，命名错了整格都会错）

```
outputs/voicebank/<exp>/refs/<说话人>/source.wav      ← 那条 ≥65s 的连续录音（每人 1 条）
outputs/voicebank/<exp>/truth/<说话人>/same.wav       ← 四类复现文本的真实录音
outputs/voicebank/<exp>/truth/<说话人>/cross.wav
outputs/voicebank/<exp>/truth/<说话人>/emotion.wav
outputs/voicebank/<exp>/truth/<说话人>/long.wav
```

说话人 id 建议用 `s01/s02/s03`（别用真名，脱敏从命名开始）。

## 3. D2 · 一条命令链（建实验 → 切档 → 合成 → 测量）

```bash
# 0) 后端必须在跑（源码模式；media 就是项目 media/）
cd m2_server && VM_SERVER_HOST=127.0.0.1 VM_SERVER_PORT=8000 ../.venv/Scripts/python.exe server.py &
cd ..   # 回到仓库根

# 1) 建矩阵 + 目录骨架
.venv/Scripts/python.exe tools/voicebank_eval.py plan --exp pilot1 \
    --speakers s01,s02,s03

# 2) 每人的连续录音 → 前缀切四档（★ 一条录音只能切一个人的档）
for s in s01 s02 s03; do
  .venv/Scripts/python.exe tools/voicebank_eval.py split --exp pilot1 \
      --speakers $s --source outputs/voicebank/pilot1/refs/$s/source.wav
done

# 3) 批量合成 48 格（2026-10-08 新增的工具；可断点续跑）
.venv/Scripts/python.exe tools/voicebank_synth.py --exp pilot1 --dry-run   # 先看计划
.venv/Scripts/python.exe tools/voicebank_synth.py --exp pilot1             # 真跑，约 15–25 分钟
#   首格会等 worker 加载模型（1–3 分钟）属正常；跑完复查音色库无 vbsyn_ 残留

# 4) 客观测量（emb_sim / asr_overlap 需要 worker 8001，正在跑就有）
.venv/Scripts/python.exe tools/voicebank_eval.py measure --exp pilot1 --with-emb --with-asr

# 5) 出盲听材料（key.csv 自己留，sheet.csv 发给听者）
.venv/Scripts/python.exe tools/voicebank_eval.py listen --exp pilot1
```

★ 想省时间可以先只跑一个条件：`--conditions same`（链路完全一样，样本从 48 变 12）。
**但 RQ2（跨文泛化）就没数据了** —— 初稿引结论时要说清。

## 4. D3 · 听测怎么发、怎么收

1. 把 `outputs/voicebank/pilot1/listen/sheet.csv` 发给每名听者（**每人一份，让他们改名保存**，
   别覆盖原件）。`key.csv` 是揭盲表，**绝对不能发**。
2. 播放：按 `listen/playlist.txt` 的顺序放，同一副耳机、音量固定。
   每条的 `mos`（1–5 自然度）必填；有 truth 对照的填 `abx`（0/1）。本实验**有** truth，所以两个都填。
3. 收齐后合并 + 出报告：

```bash
.venv/Scripts/python.exe tools/voicebank_eval.py merge-listen --exp pilot1 \
    --sheets 甲.csv,乙.csv,丙.csv,丁.csv,戊.csv
.venv/Scripts/python.exe tools/voicebank_eval.py analyze --exp pilot1 \
    --subjective outputs/voicebank/pilot1/subjective.csv
```

4. 报告在 `outputs/voicebank/pilot1/report.md`。**先看这三样**：
   - RQ1 的「饱和档」是 `30s` / `still_climbing` / `non_monotonic` / 不可判定（四种含义不同，别混）；
   - RQ3 的 Spearman 系数绝对值 ≥0.7 才有资格说"客观指标可替代人工听测"，< 0.5 就写"相关性不足"；
   - `provenance.json` 里每格的 `ref` 是不是自己那一档（**自变量标签的唯一机械证据**）。

## 5. 写进申报书 §4.2 的模板（诚实口径，照填）

> **现有结论（pilot，n=3 说话人 / 8 名听者）**：在 3/10/30/60 秒四档参考音下，
> `emb_sim` 中位数由 X 升至 Y，饱和判据给出 **`<结论>`**；
> 跨文条件相对同文条件下降 **Z**；客观指标与 MOS 的 Spearman 系数为 **r=…（n=…）**，
> **尚不足以支持**"客观指标可替代人工听测"的结论。
> 本结果为**小样本试跑**（健康说话人、单机单卡、中文、n=3），
> 用于验证评测链路与观察趋势方向，**不作为最终研究结论**。

三段红线（协议 §9）：不宣称医疗效果；不宣称"首次/领先/唯一"；
已有工程基础是**前期积累**、不是本项目的研究产出。
