## 一、项目概述、背景、现状、自我评述

### 1.1 项目概述

本项目以**「减轻录课人群的用嗓负担」为应用定位**：录课、网课、微课制作是教师与师范生的日常，连续数十分钟的讲解与反复重录，让**用嗓负担**成为真实而普遍的问题（见 §1.2）。让"机器用你自己的声音把课录出来"有两条可行路径——**讲稿逐页转旁白**与**提前保存音色续录**；两条路径共同的技术前提是：**复现的声音必须"像你、且像真人"**。本项目即在这一前提下，研究**本地离线、秒级参考音**条件下的**声音复现质量边界**，关注对象覆盖教师、师范生、播音主持、客服等**职业用嗓人群**。

具体而言：我们研究"**给克隆系统多少秒的参考音，才能复现出可接受的声音**"这一**目前尚无系统答案**的问题，并回答"**客观声学指标能否替代人工听测**"这一方法论问题。

本项目**不发明新的语音合成模型**，而是将已有成熟模型（Qwen3-TTS 少样本克隆、RVC 音色转换）工程化为一个**可控、可复现的实验平台**，用严格协议测量"质量—代价"关系，并把测量结果**反哺**为一套**自动质量门禁**，让用户保存自己声音时能得到诚实的"**录多久就够**"的答案。

### 1.2 研究背景

**（1）录课是职业用嗓负担的集中场景，嗓音损伤是真实且高发的风险**

- **录课/网课是用嗓负担的集中场景**：连续讲解与反复重录让嗓部长时间高负荷；教师、师范生、播音主持、客服等群体的共同特征是**以嗓音为生产工具**——这是本项目以"减负"为定位的现实基础。
- 国内流行病学资料显示，普通人群嗓音疾病发病率约 **6%**，中小学、幼儿园教师可达 **33.81%**（网络公开转载数据，**立项后将核验一手文献**）；国际上已有"教师嗓音疾病全球患病率"的系统综述与 meta 分析（Cutiva 等）——**该人群的流行病学基础为学界所承认**。教师职业病中明确包含慢性咽炎、声带小结、声带息肉。
- **师范生是未来的教师**：研究对象、目标人群、学校身份三者重合，**校地契合度最高**，且本项目**不涉及任何患者**。

**（2）"提前保存声音"是被认可的需求，但现有方案都有硬缺口**

| 现有方案 | 录制门槛 | 硬缺口 |
|---|---|---|
| 传统声音银行（Acapela / SpeakUnique / ModelTalker 等） | **需录 50–200 句** | 录制负担重，难以坚持 |
| Apple Personal Voice 等厂商功能 | 免费、端侧 | **仅限 Apple 设备**，Windows 无对应能力 |
| 云端 AI 语音克隆（ElevenLabs 等） | 1 分钟即时克隆，10 分钟以上才接近本人 | **必须联网**；据公开使用指南，医院、护理机构、飞机等**无网/弱网环境无法使用** |

> ★ **真正的缺口**不是"Windows 上没人做"，而是**"离线可用性"**——对处于无网环境的人群，联网方案在结构上就不适用，**有公开出处可引**。

**（3）关键的研究空白**

在"**本地离线 + 秒级参考音**"这一格中，**"质量代价究竟有多大"没有被系统回答过**：

- 现有小样本克隆工作多报告"最好情况"演示样例，**缺少对参考音时长的系统扫描**；
- 少数做了时长分析的工作，多用**不同来源、不同录制条件**的音频，**无法排除混淆因素**；
- **客观指标与主观听感的相关性**在小样本克隆场景下**缺少专门验证**，"自动质量门禁"缺乏依据。

**这三点，正是本项目要回答的问题。**

### 1.3 国内外研究现状

| 方向 | 现状 | 与本项目的关系 |
|---|---|---|
| 少样本 / 零样本语音克隆 | Qwen3-TTS、YourTTS、Seed-VC 等，**秒级参考音即可生成可懂语音** | **直接复用**，不重复造轮子 |
| 声音银行（Voice Banking） | 临床领域成熟产品，**以"多录音"换质量** | **文献口径对照**，不做实验 |
| 端侧 / 离线语音合成 | 已有尝试，**平台覆盖与质量边界报告不一致** | 补充"**离线、时长—质量**"系统数据 |
| 语音质量客观评价 | PESQ、STOI、HNR、jitter/shimmer、谱倾斜、MOS 预测 | **验证其能否用于自动门禁**（RQ3） |
| **离线 + 秒级小样本 + 质量边界系统评测** | ★ **公开文献未见系统回答** | **本项目切入点（不宣称"首次"）** |

### 1.4 自我评述

> 按申报书惯例，本节如实陈述**优势、不足与应对**。

**优势**

1. **前期基础扎实，可行性风险低。** 团队已独立完成一个可运行的桌面端实时语音系统（后端约 **3.8 万行 Python**、前端约 **4 万行 TS/TSX**、**2,847 个自动化测试**、**27 个能力插件**，完整 CI 门禁，**已在 GitHub 开源**，详细口径见 §4.1）。本项目所需的克隆引擎、变声链路、客观指标计算、盲听平台**均已存在并经过测试**——立项后可直接进入数据采集，**不是从零搭建**。
2. **研究问题具体可测。** RQ1–RQ3 均对应明确的量化指标（相似度余弦、HNR、H1-H2、谱倾斜、jitter/shimmer、WER、MOS、ABX），**每个问题都有可执行的测量手段**。
3. **评测引擎、听测平台与实验协议已就绪。** 评测引擎 1559 行 + 99 个测试，《嗓音保存评测协议》已撰写完成，**不依赖 GPU 即可复现**；主观听测平台**支持手机扫码盲听**（见 §2.2），被试无需到场。

**不足与应对**

| # | 不足（如实陈述） | 应对措施 |
|---|---|---|
| 1 | **主观听测（RQ3）团队尚无实施经验** | 先做小规模预实验（2 名被试、2 名评分者）跑通流程，请指导老师把关方法；项目内已有手机扫码盲听平台，组织成本低 |
| 2 | **被试招募依赖院内协调，时间不完全可控** | 2026 年 10 月内即启动招募；每人仅需录制约 65 秒（见 §2.4），参与成本低 |
| 3 | **团队为本科生，统计方法需要补课** | 立项后 2 个月内完成自学并提交笔记，关键分析由指导老师复核 |
| 4 | **算力有限**（单机消费级 GPU） | 实验规模按 §2.4 控制，单机可承受；批量评测夜间运行 |
| 5 | **合成引擎为已有模型，不在模型层面做原创** | 创新落在"关注对象与研究视角"上（见下方创新点），核心贡献是实验设计与相关性结论 |

**创新点（本项目的创新落在"关注谁"与"怎么衡量"上，而非算法本身）**

1. **关注对象的转移：从"炫技场景"转向录课减负的真实需求。**
   当前声音克隆多服务于**创作、娱乐与内容生产**，评价标准是"像不像"；而**录课与职业用嗓人群**的真实诉求是"**用嗓减负**"。本项目**把这一减负需求作为研究定位**，并把获取门槛（录制负担、网络依赖、隐私、成本）纳入约束条件——这一定位转移本身就是创新所在。
2. **衡量标准的转移：从"最好情况演示"转向"可操作的代价边界"。**
   现有工作**不回答"录多久才够"**。本项目以**参考音时长为自变量**系统扫描，给出可操作结论，并形成**自动质量门禁**。
3. **方法学上的补充：验证"客观指标能否替代人工听测"。**
   该相关性在小样本克隆场景缺少专门验证，直接决定自动门禁是否可信；本项目同时采集**客观指标**与**主观 MOS/ABX**并做相关性分析。

> **对照对象与依据**：① 对照 Apple / 声音银行 / 云端克隆的**人群覆盖与门槛**；② 对照现有工作**缺少时长扫描**的现状；③ 对照同类研究**缺少客观—主观相关性验证**的现状。**不使用"首次 / 领先 / 唯一"等表述。**

## 二、目的意义、技术水平、基本思路、研究方案及路线、适用范围或推广前景

### 2.1 目的意义

**目的**：建立一套**可复现的测量方法**，回答"本地离线、秒级参考音条件下的声音复现质量边界"这一问题，并据此给出**面向普通用户的可操作结论**（"要保存自己的声音，最少录多久？"）。

**意义**：

1. **对录课人群与职业用嗓人群**：为"用嗓减负"提供一条**不依赖网络、不依赖特定厂商设备**的本地路径——讲稿转旁白复用本人音色、嗓音欠佳时用已保存的声音续录；这条路径能否成立取决于**复现质量是否可用**，其代价（录多久才够）正是本研究要回答的问题。
2. **对研究方法**：补充"参考音时长 → 复现质量"的**系统性、控制变量的实验数据**，并对"客观指标能否替代人工听测"给出**实证结论**——对同类研究具有方法学参考价值。
3. **对教学场景与人才培养**：为微课配音、课程录制的**本地化、离线化生产**提供技术路径，让"录课"对嗓子的依赖从"必须本人开口"变为"**可以选择**"；同时本项目是**完整的研究训练**——文献调研、实验设计、数据采集、统计分析、论文撰写，全链条由本科生承担。

### 2.2 技术水平

**（1）前期积累已达到的技术水平（已实测）**

| 能力 | 现状 | 证据等级 |
|---|---|---|
| 实时语音转换延迟 | 消费级 GPU（RTX 5060 8GB）**端到端 p50 ≈ 300 ms / p95 ≈ 360 ms**；单块推理 p50 30 ms（2,017 样本日志） | ✅ 本机实测 |
| 小样本声音克隆 | Qwen3-TTS 已跑通，**秒级参考音**可生成语音 | ✅ 本机实测 |
| 长文本语音合成 | 91 句连续合成**零失败**，RTF 0.53 | ✅ 本机实测 |
| 客观指标栈 | HNR、H1-H2、谱倾斜、jitter、shimmer **已实现并可批量运行** | ✅ 本机实测 |
| 音频溯源水印 | 已落地（458 + 139 行），嵌入后仍可检出并给出概率 | ✅ 本机实测 |
| 主观听测平台 | 已落地（464 + 187 + 350 行，含手机端）；盲号**不下发身份**，结果只追加 | ✅ 本机实测 |
| 声音档案纵向随访 | 同一人不同时间复录 → 三灯指标按时间出趋势 | ✅ 本机实测 |
| 讲稿驱动录课 | 已落地（393 行）：PPT 备注页零依赖解析 → 逐页旁白音轨 + 时长清单 | ✅ 本机实测（链路） |
| 音频注入任意应用 | 虚拟声卡路由，**微信 / 游戏场景已验证** | ✅ 本机实测 |

> **★ 延迟口径（避免误读）**：端到端 p50 ≈ 300 ms 是三段之和——分块缓冲 250 ms + 单块推理 30 ms + 驱动缓冲约 20 ms（标称），**不宜压成一个数报**；`game` 档约 400 ms（以省资源换延迟）。


**（2）本项目拟达到的技术水平（目标）**

- 建成一套**可复现的评测流水线**：给定说话人与参考音时长，自动输出 7 类客观指标；
- 按 §2.4 规定规模完成**客观评测（192 个样本）与主观听测（24 名听测被试）**，并给出客观—主观相关性结论；
- 产出一套**自动质量门禁**规则，并报告其与人工判断的一致率。

> **技术要求的两条硬边界**：① **所有语音数据全程本地处理，不上传**；② **指标计算不依赖 GPU**，结论可被第三方复现。

### 2.3 基本思路

**一句话思路：不发明新模型，而是把已有成熟模型工程化成可控实验平台，用它把"质量边界"这个尚未被系统回答的问题回答掉。**

```
① 已有成熟模型表现够好（秒级参考音即可生成可懂语音）→ 不必自训模型
② 问题变成：「到底给多少参考音才够？」← 缺系统答案的地方
③ 要回答它必须控制变量：同一说话人、同一麦克风、同一房间，只改时长
④ 所以做"测量平台 + 严格协议"，而不是"更大的模型"
⑤ 输出诚实答案：录多久就够 → 固化为自动质量门禁
```

**这个思路的价值**：把"**能不能用**"这种凭感觉的问题，转化为"**在什么条件下、以什么代价可用**"这种**可用数据回答、可复现可验证**的问题。

### 2.4 研究方案与技术路线

**（1）研究问题**

| 编号 | 研究问题 | 类型 |
|---|---|---|
| **RQ1（主）** | 参考音时长从 3s 到 60s，复现质量如何变化？**收益在何处饱和？** | 定量、主效应 |
| **RQ2** | 不同文本条件（同文/跨文/跨情感/长句）下，同一参考音的质量差异有多大？ | 定量、交互效应 |
| **RQ3** | 客观指标与人工评分（MOS/ABX）相关性如何？**能否替代人工听测做自动门禁？** | 方法学（研究训练核心） |

**（2）实验设计**

| 维度 | 设定 |
|---|---|
| **被试（说话人）** | **N = 12**（师范生，男女各半），安静房间 + 统一麦克风 |
| **自变量：参考音时长** | **3s / 10s / 30s / 60s** —— ★ **同一批录音按前缀截取**，说话人、麦克风、房间完全一致 |
| **条件：复现文本** | ① 同文　② 跨文（日常句）　③ 跨情感（高兴/生气/悲伤）　④ 长句（> 30 字） |
| **客观指标** | 声纹余弦、HNR、H1-H2、谱倾斜、jitter/shimmer、ASR 回译 WER |
| **主观评测** | MOS 自然度（5 分制）+ ABX 相似度；**盲听、随机化、不显示条件**，手机扫码参与 |
| **对照（文献口径）** | 声音银行 50–200 句、云端 1 分钟克隆 —— **仅作文献对照，不做实验** |

**样本规模**：12 人 × 4 档 × 4 条件 = **192 个合成样本** + **24 名听测被试**。

> ★ **档位定义的关键说明**：四档是"**对同一段录音按顺序截取前 N 秒**"，因此**必须由同一人在同一条件下一次录制完成**——这正是本项目不能使用公开语料或网络素材替代的原因；被试**只需连续朗读约 65 秒**（最长档 60s）即可切出全部四档。

**（3）技术路线（五阶段）**

```
阶段一  协议与平台   → 评测协议定稿、录音 SOP、知情同意书模板
阶段二  数据采集     → 12 名被试录音（一次录制、前缀切档）、质量筛查
阶段三  客观评测     → 192 样本 × 7 指标批量运行、统计分析（RQ1/RQ2）
阶段四  主观评测     → 24 人 MOS/ABX 听测、客观—主观相关性分析（RQ3）
阶段五  反哺与结题   → 自动质量门禁规则、论文/软著/结题报告
```

**（4）分析方法**

1. **主效应**：参考音时长 → 各指标（重复测量 ANOVA / 混合效应模型）
2. **饱和点**：找出"再增加时长、收益低于阈值"的档位 → 回答"**最少要录多久**"
3. **相关性**：客观指标 vs MOS / ABX（Spearman / PLCC / SRCC）
4. **门禁验证**：用相关性最高的指标组合设阈值，验证"自动门禁 vs 人工判断"一致率

**（5）诚实边界（主动声明，不作超出数据的推断）**

- 以**健康说话人**模拟录制条件，**不是患者数据**，**不做任何疗效声称**；
- 样本量有限（12 名说话人 / 24 名听测者）、单机单卡、单一语言（中文）；
- 结论适用范围限于**本项目实验条件**，不外推为普遍结论。

### 2.5 适用范围或推广前景

**（1）适用范围**

| 对象 | 场景 | 说明 |
|---|---|---|
| **教育教学场景（主打）** | 微课/网课录制的**用嗓减负**：讲稿/备注**逐页转旁白**（复用本人音色）、嗓音欠佳时续录；课程音频**本地、离线**生产 | 与师范院校培养方向直接相关；已有讲稿录课链路（见 §4.1） |
| **职业用嗓人群** | 教师、师范生、播音主持、客服的**嗓音档案保存** | 研究对象与被试来源 |
| **嗓音障碍人群** | 可能失去嗓音者的**声音保存与辅助沟通** | ⚠️ 属**辅助沟通**，**不涉医疗用途声称** |
| **研究场景** | 提供**可复现的评测协议与流水线** | 指标计算不依赖 GPU，便于复核 |

**（2）推广前景**

1. **开源与插件化**：代码已开源、插件化架构，第三方可二次开发与场景适配；
2. **离线是刚性需求**：医院、护理机构、航班等**无网/弱网环境**中云端方案结构上不可用，本地方案不可替代；
3. **与师范培养的结合**：师范生嗓音建档与**录课减负实践**是天然落地场景——学生基数大、需求真实、与专业相关；
4. **结论的通用价值**："**参考音时长—质量**"数据与门禁结论对任何少样本克隆应用都有参考价值；
5. **从"一次保存"到"长期跟随"**：已具备**同一人跨时间复录**能力（见 §4.1），提供**发声状态趋势参考**（⚠️ 非健康判断）。

**（3）边界（诚实声明）**

- ⚠️ **不承诺医疗效果**：定位为**声音保存与辅助沟通**，随访只呈现**趋势参考**，不作诊断性表述；
- ⚠️ **能力边界**：水印只称"**可检出、可溯源**"，不称"防伪"；消费级 GPU 未验证大规模并发；无障碍为在研模块。
