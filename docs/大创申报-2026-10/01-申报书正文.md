## 一、项目概述、背景、现状、自我评述

### 1.1 项目概述

本项目**把声音保存的关注对象从创作与娱乐场景，转向职业用嗓人群的真实负担**（教师、师范生、播音主持、客服等面临**不可逆嗓音损失风险**的群体），在此基础上研究**本地离线、秒级参考音**条件下的**声音保存与复现质量边界**问题。

具体而言：我们研究"**给克隆系统多少秒的参考音，才能复现出可接受的声音**"这一**目前尚无系统答案**的问题，并回答"**客观声学指标能否替代人工听测**"这一方法论问题。

> **为什么"关注对象"本身是创新点**：现有声音克隆方案（Apple Personal Voice、云端克隆服务、传统声音银行）均以"像不像"为核心指标，**从设计上未考虑使用者的实际负担**——录制门槛高（50–200 句）、依赖特定设备（仅 Apple）、需要联网（无网或隐私敏感场景不可用）。本项目**以这一人群"负担得起"为约束条件**去重新定位"声音保存"这件事，研究的正是这一约束下的**质量边界**。

本项目**不发明新的语音合成模型**，而是将已有成熟模型（Qwen3-TTS 少样本克隆、RVC 音色转换）工程化为一个**可控、可复现的实验平台**，用严格的实验协议去测量"质量—代价"之间的关系，并将测量结果**反哺**为一套**自动质量门禁**，使普通用户在保存自己声音时，能得到一个诚实的"录多久就够"的答案。

### 1.2 研究背景

**（1）职业用嗓人群的嗓音损伤是真实且高发的风险**

- 国内流行病学资料显示，普通人群嗓音疾病发病率约 **6%**，而中小学、幼儿园教师患病率可达 **33.81%**（网络公开转载数据，**本项目立项后将核验一手文献**）。
- 国际上已有关于"教师嗓音疾病全球患病率"的系统综述与 meta 分析，以及"职业用嗓与嗓音疾病关联"的 meta 分析（Cutiva 等）——**该人群的流行病学基础为学术界所承认**。
- 教师职业病中明确包含慢性咽炎、声带小结、声带息肉。
- **师范生是未来的教师**：研究对象、目标人群、学校身份三者重合，**校地契合度最高**，且本项目**不涉及任何患者**。

**（2）"提前保存声音"是被认可的需求，但现有方案都有硬缺口**

| 现有方案 | 录制门槛 | 硬缺口 |
|---|---|---|
| 传统声音银行（Acapela / SpeakUnique / The Voice Keeper / ModelTalker 等） | **需录 50–200 句** | 录制负担重，难以坚持完成 |
| Apple Personal Voice 等厂商功能 | 免费、端侧 | **仅限 Apple 设备**，Windows 平台无对应能力 |
| 云端 AI 语音克隆（ElevenLabs 等） | 1 分钟可做即时克隆，10 分钟以上才接近本人 | **必须联网**；据公开发布的使用指南，在医院、护理机构、飞机等**无网或弱网环境无法使用**；且长期订阅成本较高 |

> ★ **真正的缺口**不是"Windows 上没人做"，而是**"离线可用性"**——对行动受限或处于无网环境的人群，联网方案在结构上就不适用。这一判断**有公开出处可引**，不是我们的主观感受。

**（3）关键的研究空白**

上述三类方案的共同前提是"**你需要录很多**"或"**你需要联网**"。而在"**本地离线 + 秒级参考音**"这一格中，**"质量代价究竟有多大"没有被系统回答过**：

- 现有小样本克隆工作多报告"最好情况"的演示样例，**缺少对参考音时长这一变量的系统扫描**；
- 少数做了时长分析的工作，多使用**不同来源、不同录制条件**的音频，**无法排除说话人/麦克风/房间等混淆因素**；
- **客观指标与主观听感的相关性**在小样本克隆场景下**缺少专门验证**，导致工程上的"自动质量门禁"缺乏依据。

**这三点，正是本项目要回答的问题。**

### 1.3 国内外研究现状

| 方向 | 现状 | 与本项目的关系 |
|---|---|---|
| 少样本 / 零样本语音克隆 | 已有 Qwen3-TTS、YourTTS、Seed-VC 等工作，**秒级参考音即可生成可懂语音** | 本项目**直接复用**这些成熟模型，不重复造轮子 |
| 声音银行（Voice Banking） | 临床与辅助沟通领域已有成熟产品，**但以"多录音"为代价换取质量** | 作为**文献口径对照**，不做实验 |
| 端侧 / 离线语音合成 | 已有端侧 TTS 与端侧克隆的尝试，**平台覆盖与质量边界报告不一致** | 本项目补充"**离线条件下、参考音时长—质量**"的系统数据 |
| 语音质量客观评价 | 已有 PESQ、STOI、HNR、jitter/shimmer、谱倾斜等指标，以及在特定任务上的 MOS 预测模型 | 本项目**验证这些指标能否用于"克隆质量"的自动门禁**（RQ3） |
| **离线 + 秒级小样本 + 质量边界系统性评测** | ★ **公开文献中未见系统回答** | **本项目的切入点（不宣称"首次"，仅客观陈述检索现状）** |

**创新点（本项目的创新落在"关注谁"与"怎么衡量"上，而非算法本身）**

1. **关注对象的转移：从"炫技场景"转向被忽略的真实人群。**
   当前声音克隆的研究与应用多服务于**创作、娱乐与内容生产**，评价标准是"像不像";而**职业用嗓人群**（教师、师范生、播音主持、客服等）面临的**不可逆嗓音损失风险**是真实且高发的，他们的诉求不是音色相似度，而是"**在负担得起的前提下把声音保存下来**"。本项目**把这一人群的实际负担（录制门槛、网络依赖、隐私顾虑、成本）作为设计的出发点**——这一定位的转移本身就是本项目的创新所在。
2. **衡量标准的转移：从"最好情况演示"转向"可操作的代价边界"。**
   现有工作多报告"最好情况"的样例，**不回答"录多久才够"**。本项目以**参考音时长为自变量**做系统扫描，给出普通用户可操作的结论，并据此形成**自动质量门禁**（让系统自己判断"这段声音够不够用"）。
3. **方法学上的补充：验证"客观指标能否替代人工听测"。**
   在小样本克隆场景下，这一相关性缺少专门验证，直接决定了自动门禁是否可信。本项目同时采集**客观指标**与**主观 MOS/ABX**并做相关性分析，为该场景提供实证依据。

> **对照对象与依据**：上述每一条均对应对照对象——① 对照 Apple Personal Voice / 传统声音银行 / 云端克隆的**人群覆盖与使用门槛**；② 对照现有小样本克隆工作**缺少时长扫描**的现状；③ 对照同类研究**缺少客观—主观相关性验证**的现状。**不使用"首次 / 领先 / 唯一"等表述。**

## 二、目的意义、技术水平、基本思路、研究方案及路线、适用范围或推广前景

### 2.1 目的意义

**目的**：建立一套**可复现的测量方法**，回答"本地离线、秒级参考音条件下的声音复现质量边界"这一问题，并据此给出**面向普通用户的可操作结论**（"要保存自己的声音，最少录多久？"）。

**意义**：

1. **对职业用嗓人群**：提供一个**不依赖网络、不依赖特定厂商设备**的声音保存路径，降低"提前保存声音"的门槛。
2. **对研究方法**：补充"参考音时长 → 复现质量"的**系统性、控制变量的实验数据**，并对"客观指标能否替代人工听测"给出**实证结论**——后者对同类研究具有方法学参考价值。
3. **对教学场景**：为微课配音、课程音频的**本地化、离线化生产**提供一条技术路径。
4. **对人才培养**：本项目是**完整的研究训练**——文献调研、实验设计、数据采集、统计分析、论文撰写，全链条由本科生承担。

### 2.3 基本思路

**一句话思路：不发明新模型，而是把已有成熟模型工程化成可控实验平台，用它把"质量边界"这个尚未被系统回答的问题回答掉。**

```
① 已有成熟模型的表现已经够好（秒级参考音即可生成可懂语音）
        ↓   那就不需要自己训模型
② 问题于是变成：「到底给它多少参考音才够？」← 这才是缺系统答案的地方
        ↓   要回答它，必须排除混淆因素
③ 必须控制变量：同一说话人、同一麦克风、同一房间，只改变参考音时长
        ↓   所以要做的是"测量平台 + 严格协议"
④ 而不是"更大的模型"或"更炫的界面"
        ↓   测量结果要能直接回答用户的问题
⑤ 输出一个诚实的答案：录多久就够；并把它固化为自动质量门禁
```

**这个思路的价值在于**：把"**能不能用**"这种凭感觉的问题，转化为"**在什么条件下、以什么代价可用**"这种**可以用数据回答**的问题。后者的结论是**可复现、可验证、可被他人使用**的。

### 2.4 研究方案与技术路线

**（1）研究问题**

| 编号 | 研究问题 | 类型 |
|---|---|---|
| **RQ1（主）** | 参考音时长从 3s 增加到 60s，复现质量如何变化？**收益在何处饱和？** | 定量、主效应 |
| **RQ2** | 不同文本条件下（同文 / 跨文 / 跨情感 / 长句），同一参考音的复现质量差异有多大？ | 定量、交互效应 |
| **RQ3** | 客观指标与人工主观评分（MOS / ABX）的相关性如何？**能否用客观指标替代人工听测做自动门禁？** | 方法学（研究训练核心） |

**（2）实验设计**

| 维度 | 设定 |
|---|---|
| **被试（说话人）** | **N = 12**（师范生，男女各半），安静房间 + 统一麦克风 |
| **自变量：参考音时长** | **3s / 10s / 30s / 60s** —— ★ **同一批录音按前缀截取**，保证说话人、麦克风、房间完全一致 |
| **条件：复现文本** | ① 同文　② 跨文（日常句）　③ 跨情感（高兴 / 生气 / 悲伤）　④ 长句（> 30 字） |
| **客观指标** | 相似度（声纹余弦）、自然度（HNR）、发声健康（H1-H2、谱倾斜）、稳定性（jitter / shimmer）、可懂度（ASR 回译 WER） |
| **主观评测** | MOS 自然度（5 分制）+ ABX 相似度；**盲听、随机化、不显示条件**；听测者**手机扫码即可参与**，无需到场 |
| **对照（文献口径）** | 传统声音银行 50–200 句方案、云端 1 分钟即时克隆 —— **仅作文献对照，不做实验** |

**样本规模**：12 人 × 4 档 × 4 条件 = **192 个合成样本** + **24 名听测被试**。

> ★ **档位定义的关键说明**：四档的定义是"**对同一段录音按顺序截取前 N 秒**"。
> 这一定义决定了**必须由同一人在同一条件下一次录制完成**——这也是本项目不能使用公开语料
> 或网络素材替代的原因：**那样的素材无法保证"同一录音的前缀截取"这一控制变量条件**。
> 实际录制时，被试**只需连续朗读约 65 秒**（4 档中最长为 60s），即可切分出全部四档。

**（3）技术路线（五阶段）**

```
阶段一  协议与平台          →  评测协议定稿、录音 SOP、知情同意书模板
   ↓
阶段二  数据采集            →  12 名被试录音（一次录制、前缀切档）、质量筛查
   ↓
阶段三  客观评测（RQ1/RQ2）  →  192 样本 × 7 指标批量运行、统计分析
   ↓
阶段四  主观评测（RQ3）      →  24 人 MOS/ABX 听测、客观-主观相关性分析
   ↓
阶段五  反哺与结题          →  自动质量门禁规则、论文/软著/结题报告
```

**（4）分析方法**

1. **主效应**：参考音时长 → 各指标（重复测量 ANOVA / 混合效应模型）
2. **饱和点**：找出"再增加时长，收益低于阈值"的档位 → 回答"**最少要录多久**"
3. **相关性**：客观指标 vs MOS / ABX（Spearman / PLCC / SRCC）
4. **门禁验证**：用相关性最高的指标组合设定阈值，验证"自动门禁 vs 人工判断"的一致率

**（5）诚实边界（主动声明，不作超出数据的推断）**

- 本实验以**健康说话人**模拟"嗓音保存前的录制条件"，**不是患者数据**；
- 样本量有限（12 名说话人 / 24 名听测者），单机单卡，单一语言（中文）；
- 本项目**不做任何疗效声称**，只做"**保存与复现的质量评价**"；
- 研究结论的适用范围限于**本项目实验条件**，不外推为普遍结论。

### 2.5 适用范围或推广前景

**（1）适用范围**

| 对象 | 场景 | 说明 |
|---|---|---|
| **职业用嗓人群** | 教师、师范生、播音主持、客服等的**嗓音档案保存** | 本项目主要研究对象 |
| **嗓音障碍人群** | 因疾病或手术可能失去嗓音者的**声音保存与辅助沟通** | ⚠️ 属**辅助沟通**范畴，**不涉及任何医疗用途声称** |
| **教育教学场景** | 微课配音、课程音频的**本地、离线**生产；讲稿/课件备注**逐页转旁白** | 与师范院校培养方向直接相关；已有可用的"讲稿驱动录课"链路（见 §4.1） |
| **研究场景** | 为同类研究提供**可复现的评测协议与流水线** | 评测引擎不依赖 GPU，便于他人复核 |

**（2）推广前景**

1. **开源与插件化**：项目代码已开源并采用**插件化架构**，第三方可在此基础上做二次开发或场景适配；
2. **离线是刚性需求**：在医院、护理机构、航班等**无网或弱网环境**，云端方案在结构上不可用；本地方案在这些场景具有不可替代性；
3. **与师范培养的结合**：师范生嗓音健康建档是一个**天然的落地场景**——学生基数大、需求真实、与专业培养相关；
4. **结论的通用价值**：本研究产出的"**参考音时长—质量**"数据与"客观指标能否替代听测"的结论，**对任何使用少样本克隆的下游应用都有参考价值**，不限于本项目；
5. **从"一次保存"到"长期跟随"**：系统已具备**同一人跨时间复录**的能力（声音档案纵向随访，见 §4.1），可把"一次建档"扩展为"长期跟随"，为职业用嗓人群提供**发声状态变化的趋势参考**（⚠️ 这是趋势参考，不是健康判断，见下方边界声明）。

**（3）边界（诚实声明）**

- ⚠️ 本项目**不承诺任何医疗效果**；系统定位为**声音的保存与辅助沟通**，而非治疗；随访功能只呈现**发声状态的趋势参考**，不作任何诊断性表述；
- ⚠️ **溯源水印的能力边界**：本项目实现的是"**可检出、可溯源**"（音频被转码后仍能检出并给出置信概率），**不宣称"防伪"或"无法去除"**；
- ⚠️ 当前方案基于**消费级 GPU**，**未验证大规模并发场景**；
- ⚠️ 无障碍方向为**在研模块**，尚未完成产品化验证。
