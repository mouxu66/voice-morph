# 前端自动构建 - 快速开始

## 🚀 使用方法

### 1. 启动监听器（一次）

```bash
cd web
npm run watch-ship
```

保持这个终端窗口运行，它会一直监听你的代码变化。

### 2. 修改前端代码

像往常一样编辑 `web/src/` 下的任何文件（`.tsx`, `.ts`, `.css` 等）。

### 3. 等待自动构建

- 修改后等待 **2 秒**（防抖机制）
- 看到 "🚀 执行：npm run build" 表示开始构建
- 看到 "✅ 构建完成！" 表示成功

### 4. 重启应用查看效果

⚠️ **重要：** 必须完全退出桌面应用（包括桌宠），然后重新打开才能看到新界面。

---

## 💡 提示

- **开发调试模式**：只构建不同步
  ```bash
  npm run watch-ship -- --dev
  ```

- **停止监听**：在终端按 `Ctrl+C`

- **检查环境**：
  ```bash
  node test-watch-ship.cjs
  ```

---

## ❓ 常见问题

**Q: 为什么应用还是旧版本？**  
A: 确保完全退出了应用（桌宠会在系统托盘常驻，需要右键退出）。

**Q: 构建失败了怎么办？**  
A: 查看终端错误信息，通常是 TypeScript 类型错误或缺少依赖。

**Q: 可以监听其他目录吗？**  
A: 当前只监听 `web/src/`，这是推荐的做法。
