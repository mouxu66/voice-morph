# ⚠️ 可选能力的重依赖**不在这里** —— 它们声明在 `m2_server/plugins/<id>/plugin.json`
#    的 `extras.python` 里，由 `tools/setup_env.ps1` 按启用集安装（插件化第 5 步）。
#    为什么分开：以前 `pip install -r requirements.txt` 会把 torch(2GB) + demucs

#    实测核心插件里**没有任何模块**在模块级 import torch（见下「说明 1」）。
#
# ⚠️ torch / torchaudio 必须从 CUDA 索引装，**不能**直接 pip install
#    （会装成 CPU 版 → 显存不可用、推理静默失效）。它们归
#    `sound.offline-vc`（Seed-VC 推理跑在主 .venv，seed_vc.py:11）与
#    `sound.audition`（打分器子进程用 sys.executable 拉起，audition_api.py:207）。
#    装法见 tools/setup_env.ps1 的 -Preset。

# 说明
# 1) 可选依赖现在**只在清单里**，一处权威（别再把它们加回本文件）：
#      Pillow        → hook.wechat      （微信录音浮层截图 + 绿钮质心定位）
#      demucs        → sound.workshop   （人声分离；它自己会拉 torch）

#      torch,torchaudio → sound.offline-vc / sound.audition
#      qwen-tts      → sound.tts        （走独立 venv312，见说明 2）
#    加/改可选依赖时，**清单和本注释一起改**，并跑 tools/audit_licenses.py。
