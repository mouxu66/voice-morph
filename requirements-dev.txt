# 开发 / CI / git 钩子依赖（**瘦环境**：故意不含 GPU 推理栈）
#
# 为什么不是 `-r requirements.txt`：那会拉 torch / torchaudio / demucs（>2GB、
# CI 上要 5~8 分钟），而本项目的测试全部用 monkeypatch 隔离了模型、微信真机与
# ffmpeg，跑测试并不需要它们。2026-09-13 实测（真建瘦 venv 跑，不再靠"屏蔽"）：
# 全量 573 passed + 3 skipped（3 例按设计 skip）。
#
# ⚠️ 两个刻意不装的包，别"顺手补上"：
#   - torch      ：test_server.py 里唯一依赖它的用例用 importorskip 自行跳过；
#                  装了就多 2GB 下载，不装反而更快。
#   - librosa    ：test_effects.py 的 2 个用例专门验证"librosa 缺失时效果器
#                  直通"这条降级路径，装了反而会把它们 skip 掉。
# 若哪天有人给测试路径加了重依赖，CI 会在收集期大声失败——把缺的包补到这里，
# 并顺手确认它是不是真的必须。
pytest>=8
#  pyproject.toml 的 addopts 默认就带 `--cov=m2_server --cov-report=…`，
#  所以**没有 pytest-cov 时 pytest 连参数解析都过不去** —— 报的是
#  `unrecognized arguments: --cov=m2_server`，看着像配置写错了，实际是缺插件。
#  2026-09-19 用 `tools/check.py --ci-fidelity` 在瘦环境里实测复现（此前本机一直绿，
#  是因为 .venv 里**手工装过**它、而它从没进过任何 requirements）。
#  ⚠️ 别改成“给 CI 加 `-o addopts=` 去掉覆盖率”：ci.yml 的立身之本就是
#  「与本地、与 git 钩子跑同一条命令」，去掉就等于把这条不变量换成了两套命令。
pytest-cov
